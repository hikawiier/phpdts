# 第一幕：庇护所与新手区资源设计案 (v0.7)

本案以“冷面滑稽与一本正经胡说八道”为文案风格，结合“精细生存阻力与道具多功能性”的可玩性深度，以及“多维度正向反馈与渐进软锁”的成长体系，对垃圾岛开局阶段进行全面设计。

---

## 一、 设计哲学与调性控制

1. **客观的滑稽 (Quirky but Gentle)**：系统文案必须使用极度冷静、近乎客观的语气，描述离奇、好笑的流浪汉生存日常。避免对角色和动物进行带有虐待感的肉体改造（如将冰盒绑在猫背上，而非塞进体内），保持温馨荒诞的互动。
2. **多功能道具（Tools as Materials）**：道具的用途是流动的。一个道具既是武器，也是合成材料，更可以是地图探索时的交互工具（通过后端 Tag 系统驱动）。
3. **多维软锁（Multidimensional Growth）**：玩家面临生存与地图限制时，有多种并行的成长路线（拾荒、烹饪、战斗）去突破限制，所有行为都能带来正向反馈。
4. **错位叙事控制**：第一幕不暴露“太空船”真相，保持“异世界垃圾场地表拾荒”的氛围。

## 二、 场景与交互物件

### 2.1 苹果的庇护所 (The Sanctuary)
*   **废弃排风口 (The Ventilation Outlet)**
    *   **描述**：从地底下伸出来的粗大铁管，正温和地冒着带有机油味的热风。上面架着个铁丝网，用作火炉。猫每天都躺在铁网上面烘干肚皮。
    *   **交互**：烤火（回复精力），或者丢弃无用道具（当作垃圾烘烧掉）。
*   **废旧铁舱 (The Iron Capsule)**
    *   **描述**：一个半埋在泥地里、舱门损坏的退役单人舱室。里面塞满了五颜六色的旧海绵与破被子，是苹果和猫的睡袋。
    *   **交互**：存档 / 休息（回复生命与精力）。
*   **金属垃圾箱 (The Waste Bin)**
    *   **描述**：苹果用来存放拾荒小玩意的铁皮箱。每当丢进东西，它就会发出“沙沙”的喇叭声，听起来像是在清嗓子。

### 2.2 庇护所门外（新手区域）
*   **场景意象**：生锈钢铁与废料拼接的平原。代表“草”的是从地下长出来的彩色橡胶导线；巨大的舱壁斜插在地上，成为天然的遮蔽物。
*   **野外采集点**：
    *   `废弃电线 (Scrap Wire)`：从生锈铁板里像藤蔓一样长出来的花哨塑胶电线。
    *   `踩瘪的铝罐 (Crushed Can)`：风干、氧化成各种古怪形状的饮料铝罐。
    *   `发光青苔 (Bio-Glow Moss)`：寄生在生锈钢板阴暗处的发光真菌。

## 三、 生存阻力与多维度软锁 (Growth & Soft-locks)

在开局阶段，地图会通过以下三维度的身体感官限制阻止玩家前往深层区域（如获取微波炉核心或开启大门）。玩家可以通过不同的路线突破这些软锁：

1.  **光脚刺痛**：垃圾岛地表布满碎玻璃和锐利金属皮。若没有装备足部防具，玩家移动时会损失生命，并降低体力回复。
    *   *解法A (拾荒合成)*：收集海绵、电线和铝罐，合成“流浪汉厚底鞋”。
    *   *解法B (体质强化)*：通过寻找特定的废金属（如重铅块）融化在衣服或负重上，强行提升肉体强韧度以降低受伤。
2.  **雾气障目**：空气中弥漫着冷却废气，限制了视野。
    *   *解法A (工具制作)*：将发光青苔和水装入透明塑料瓶中，制作“绿光荧光瓶”用作照明。
    *   *解法B (食物进补)*：通过慢火熬制“星光流溢琥珀糖”食用，获得临时夜视状态。
3.  **重金属腹泻**：直接饮用工业废水会导致精力耗尽。
    *   *解法A (水净化)*：用废罐子和活性炭残渣制作“简易冷滤罐”净化水质。
    *   *解法B (食疗抗性)*：食用用香草味机油和焦油焖出来的“风琴焦糖土豆泥”，提高肠胃对废水毒性的忍耐力。

## 四、 鉴定机制与“越级合成”隐性加成

为了支持 Roguelike 游戏中的“逃课”与惊喜感，垃圾岛的材料鉴定系统与合成系统采用**“隐性属性判定”**：

### 4.1 隐性属性与认知升级
*   **物理实体统一**：在未鉴定状态下，所有同类材料在背包中统一堆叠和命名。例如，铅块和秘银钢板在玩家未解锁相应鉴定知识时，统一显示为 `未知金属板` 或 `一块沉甸甸的灰金属`。
*   **隐性加成判定**：若玩家在 T0 阶段偶然从危险区域拾取了高性能的“未知金属板”（其后台本质为秘银），即使玩家尚未解锁秘银的鉴定知识，直接将其用作素材合成 `流浪汉厚底鞋` 时，**合成系统仍会在后台读取材料的真实物理属性**，为产物附加“免除精力消耗”的隐藏加成。
*   **认知解锁的惊喜**：玩家在使用该装备时会发现隐藏的增益效果，但无法在 UI 上看到原因。直到玩家后续解锁了相应的鉴定知识并重新识别材料后，装备界面上的隐藏属性才会正式点亮，并显示出真实材料的来历文案（例如：*“因使用了秘银合金，该装备获得了轻盈效果”*）。

## 五、 多功能道具系统 (Tools as Materials)

每个道具都通过 Tag 系统被赋予了多重职能：

| 道具名称 | 作为武器/装备 | 作为探索工具 | 作为合成素材/配件 |
| :--- | :--- | :--- | :--- |
| **物理圣剑 (撬棍)** | 提供基础物理敲击伤害。 | 用于撬开锁死的铁箱和密闭门板。 | 电击棒的主骨架。 |
| **废弃电线** | 缠在脚上提供极微量的防滑保护。 | 可作为捆绑绳，在特定 POI 间搭建安全绳索。 | 捆扎厚底鞋、制冷塔或导电装置的连接件。 |
| **踩瘪的铝罐** | 垫在胸前提供微弱的基础物理防御。 | 用作临时舀水的容器，或盛装油脂。 | 敲平后作为流浪汉厚底鞋的金属外底。 |
| **透明饮料瓶** | 砸向敌人可造成微弱击退。 | 用来装水或废液。 | 装入发光青苔后成为“绿光荧光瓶”的手电筒外壳。 |

## 六、 玩家脑洞合成链与美食

### 6.1 脑洞装备合成
*   **流浪汉厚底鞋 (Scrap-Soled Shoes)**
    *   `踩瘪的铝罐` + `废弃电线` + `废舱床的海绵`
    *   *描述*：将饮料罐敲平作为外层钢底，内部垫上松软的海绵，再用电线缠绕在脚腕上。从此再也不怕踩到碎玻璃了。
*   **背负式制冷塔 (Backpack Cooling Tower)**
    *   `猫的背囊`（需要升级） + `废旧冰箱的制冷铁盒` + `废弃电线`
    *   *描述*：用电线把一个沉重的制冷铁盒牢牢绑在猫背上。虽然这让猫走起路来像一个摇摇晃晃的冰淇淋小车并嘟囔着“尾巴要被冻僵了”，但猫背囊里的食物再也不会腐烂了。
*   **生物能电击棒 (Bio-Stun Baton)**
    *   `物理圣剑` + `带电的兔肉` + `废弃电线`
    *   *描述*：用废电线将还在兹兹冒火花的带电兔肉捆在撬棍顶端。每次挥击受压释放的电能通过钢身传导，攻击有一定几率使敌人身体短路麻痹，但会消耗兔肉的活性。

### 6.2 天马行空的美食烹饪
*   **【微电酥皮霜降兔扒 (Dry-Aged Electro-Steak)】**
    *   *配方*：`带电的兔肉` + `废弃电线`（引雷）+ 铁网排风口烘烤。
    *   *美味描述*：*刀锋切开的瞬间，琥珀色的油脂顺着霜降纹理溢出。送入嘴里，微弱的残留电流在舌尖上像跳跳糖一样极其轻微地爆裂，瞬间唤醒了麻痹的味蕾，接着是软嫩多汁、甚至带有一点奶香的肉质在口中化开。*
    *   *效果*：大幅恢复并提升精力，获得精力充沛状态。
*   **【星光流溢琥珀糖 (Starlight Amber Candy)】**
    *   *配方*：`发光青苔` + `干瘪糖果` + `温水`
    *   *美味描述*：*折射着幽绿荧光的半透明糖块。咬下去咯嘣作响，先是老式太妃糖那浓郁得近乎化不开的焦糖甜美，随后，发光苔藓独特的冰凉薄荷感在喉咙里炸开，仿佛吞下了一整片微缩的星空。*
    *   *效果*：提供精力恢复，并获得夜视状态。
*   **【风琴焦糖土豆泥 (Accordion Baked Potato)】**
    *   *配方*：`铁皮土豆` + `香草味机油` + `焦油`
    *   *美味描述*：*剥开焦黑的硬壳，里面的土豆已经吸饱了油脂，呈现出耀眼的淡金色。用勺子轻轻一压就化成了如丝绸般细腻的土豆泥，甜润的草本香气伴随着滚烫的蒸汽扑面而来，是足以让人在寒冷废土上落泪的温暖碳水。*
    *   *效果*：大量恢复生命值。

### 6.3 食疗抗性获取事件（Elona 式随机性）
*   **安全料理**：通过合理配方（如利用地线脱电并风干）做出的熟食，提供 100% 稳定的正面状态增益。
*   **危险生食**：直接生吃 `带电的兔肉` 等生肉或有毒素材时，有固定几率触发身体“抗性跃迁”事件，**使玩家永久/长期获得被动技能**（如 `[电弧耐性]`，用于降低后续电击伤害），鼓励玩家在绝境中进行风险尝试。

## 七、 生存阻力与“吃瘪看板娘”视觉呈现（存疑）

为了在黑白终端美学下直观、滑稽且富有情感地传达生存阻力，游戏引入**【吃瘪看板娘】**系统，取代复杂的部位骨架与医学受伤数值：

### 7.1 极简状态 Tag 机制
系统不设复杂的部位受伤血条，而是将玩家的健康度简化为 **HP（生命）**、**SP（精力）**、**AP（行动力）** 以及若干个直接挂钩机制的 **身体状态 (Body Status) Tag**：
*   `[足部刺痛]`：移动时损失生命，限制探索节奏。
*   `[胃部不适]`：由于重金属腹泻导致精力/AP恢复速度大幅减半。
*   `[手臂麻木]`：由于直接生吃带电兔肉或受到重击，导致武器的物理攻击速度或命中率下降。

### 7.2 1-bit 剪纸状态立绘联动（存疑）
在左侧抽屉或主界面角落，显示一个与立绘风格高度统一 of 1-bit 剪纸风格苹果小人。小人不显示具体的医学数据，而是**根据当前持有的状态 Tag 切换吃瘪表情与滑稽姿势**：
*   **健康状态 (Normal)**：小人面无表情地背着物理圣剑（正常站姿）。
*   **足部刺痛 (Foot Hurt)**：小人单脚着地，另一只脚提起来，表情多了一对哭丧的“叉叉眼”，逗趣地展示着行路艰难。
*   **胃部不适 (Stomach Sick)**：小人捂着肚子蹲在地上，头顶冒出代表肠胃蠕动的黑线。
*   **电火花律动 (Charged)**：小人的发梢呈静电状竖起，指尖带着噼啪的静电字符。
