# Oblivions 技能/动作系统设计案（简化版）

> **MVP 目标**：将现有前端两个临时按钮（空手攻击、逃跑）整合进技能框架，并设计完整的装填区界面与页面布局。
>
> **设计原则**：一切皆技能；配置驱动分类；tick 时间戳记 CD；单技能单文件自动引用。
>
> **关联文档**：[战斗系统设计案.md](已完成任务/战斗系统设计案.md)

***

## 一、设计目标

### 1.1 必须实现

1. 后端技能框架：`skill_config.php` + `skill.main.php` + 单技能 calc 文件
2. 现有 `unarmed_strike`、`escape` 迁移到技能框架
3. 前端装填区界面：技能列表 + AP 显示 + 预装填队列 + 执行按钮
4. `skill_list` API：向前端提供技能配置与运行时状态
5. 前端技能模板：按 skill\_id 渲染名称/描述

### 1.2 不实现（不在本设计案范围）

- DoT 技能（bleed/poison 等触发型被动）
- buff/debuff 修饰型被动技能
- 武器攻击模式（weapon\_blade 等）
- 技能学习/升级系统
- AOE 范围形状

## 三、数据结构

### 3.1 skill\_config.php

```php
return [
    'unarmed_strike' => [
        'apcost'        => 0,           // AP 消耗
        'cd'            => 0,           // 冷却回合数（0=无CD）
        'target'        => 'enemy',     // 目标类型：self/enemy/all/tiles
        'range_bonus'   => 0,           // 射程补正
        'lifetime'      => 'permanent', // 生命周期：permanent/equipment/effect
        'category'      => 'attack',    // 分类：attack/escape/utility
        'damage_type'   => 'physical', // 伤害类型：physical/magical/none
        'damage_factor' => 1.0,         // 伤害系数（att × factor）
    ],
    'escape' => [
        'apcost'        => 0,
        'cd'            => 0,
        'target'        => 'self',
        'range_bonus'   => 0,
        'lifetime'      => 'permanent',
        'category'      => 'escape',
        'damage_type'   => 'none',
        'damage_factor' => 0,
    ],
];
```

**字段说明**：

| 字段            | 类型     | 说明                                                         |
| ------------- | ------ | ---------------------------------------------------------- |
| `apcost`      | int    | AP 消耗，0=免费                                                 |
| `cd`          | int    | 冷却回合数，0=无CD                                                |
| `target`      | string | self=自身 / enemy=敌对单位 / all=任意 / tiles=图格                   |
| `range_bonus` | int    | 射程补正，加到基础射程上                                               |
| `lifetime`    | string | permanent=永久持有 / equipment=装备赋予(不持久化) / effect=战斗中施加(到期消失) |

**不含字段**：name/desc/icon/category（由前端 `skill-templates.js` 按 skill\_id 渲染）

### 3.2 skillpara JSON

```json
{
    "unarmed_strike": {
        "lstact": 0
    },
    "escape": {
        "lstact": 0
    }
}
```

**字段说明**：

| 字段       | 类型  | 说明                                                                              |
| -------- | --- | ------------------------------------------------------------------------------- |
| `lstact` | int | 上次使用该技能的游戏刻（`$gamevars['obl_tick']`）。0=从未使用。CD 判定：`current_tick - lstact >= cd` |

**结构规则**：

- 每个 skill\_id 作为 key，直接索引
- 每个技能的运行时状态作为该 key 下的子数组
- MVP 只有 `lstact` 一个字段

### 3.3 前端技能模板（skill-templates.js）

 * @param array &$battle_cache

 * 技能执行（由 battle_once_excute 调用）

 * 1. 自动引用 calc/{skill_id}.calc.php

 * 调用时机：在 obl_calc_damage() + battle_apply_damage() 之后
 *
 * @param array &$actor_data 先攻者数据

 * @param array &$target_data 目标数据
 * @param BattleLogCollector &$obl_battle_log
 * @param array &$battle_cache
 */
function skill_execute(&$actor_data, $act_id, &$target_data, &$obl_battle_log, &$battle_cache) {}

/**
 * 获取玩家可用技能列表（由 skill_list API 调用）

 * 职责：
 * 1. 遍历 skillpara 的 keys
 * 2. 对每个 key 查 skill_config 获取配置
 * 3. 附加运行时状态：lstact、current_tick、on_cd（是否在CD中）、available（是否可用）

#### battle.calc.php - obl\_calc\_damage()

```php
// 修改前：
function obl_calc_damage(&$actor_data, $target_data, $atk_act, $battle_cache) {
    $damage = $actor_data['att'] - $target_data['def'];
    $damage = max(1, $damage);
    return $damage;
}

// 修改后：读取 damage_factor 和 damage_type
function obl_calc_damage(&$actor_data, $target_data, $atk_act, $battle_cache) {
    include_once GAME_ROOT . './oblivions/include/game/skill/skill.main.php';
    $config = skill_get_config($atk_act);

    // 无伤害技能返回 0
    if (!$config || $config['damage_type'] === 'none') {
        return 0;
    }

    $damage_factor = $config ? $config['damage_factor'] : 1.0;
    $damage = ($actor_data['att'] * $damage_factor) - $target_data['def'];
    $damage = max(1, $damage);
    return $damage;
}
```

### 5.2 技能列表区（右上半区）

**数据来源**：调用 `skill_list` API 获取

**渲染内容**（每个技能）：

- 技能名称（从 `skill-templates.js` 查询）
- 技能描述
- AP 消耗
- CD 状态（若在 CD 中，置灰显示剩余回合）
- 可用状态（AP 不足或被限制时置灰）

**交互**：

- 点击技能 → 进入瞄准模式（target=enemy 时）或直接加入队列（target=self 时）
- CD 中或不可用的技能不可点击

### 5.3 装填区（右下半区）

**AP 显示**：

- 当前 AP / 最大 AP（数字）
- AP 可视化条（进度条）
- 预扣除：队列中每加入一个技能，前端模拟扣除 AP（仅视觉效果）
- AP 为负时，不允许再加入 AP 消耗 > 0 的技能

**预装填队列**：

- 按顺序显示已装填的动作
- 每项显示：序号 + 技能名 + 目标 + AP 消耗
- 每项有 \[×] 移除按钮
- 拖拽可调整顺序（可选，MVP 可不做）

**执行按钮**：

- 点击后提交所有队列中的动作到后端
- 提交后清空队列
- 队列为空时按钮置灰

### 5.4 瞄准模式

**触发**：点击 target=enemy 的技能

**表现**：

- 地图上高亮射程内的可选目标
- 非可选目标（射程外、已死亡）置灰
- 鼠标悬停目标显示简单信息

**操作**：

- 点击目标 → 加入预装填队列，退出瞄准模式
- 按 ESC 或点击空白 → 取消瞄准

## 六、API 规范

### 6.1 skill\_list 接口

**请求**：

```
GET /api_v2.php?cmd=skill_list
```

**响应**：

```json
{
    "success": true,
    "skills": [
        {
            "act_id": "unarmed_strike",
            "apcost": 0,
            "cd": 0,
            "target": "enemy",
            "range": 1,
            "lstact": 0,
            "current_tick": 15,
            "on_cd": false,
            "available": true
        },
        {
            "act_id": "escape",
            "apcost": 0,
            "cd": 0,
            "target": "self",
            "range": 0,
            "lstact": 0,
            "current_tick": 15,
            "on_cd": false,
            "available": true
        }
    ],
    "player_ap": 5,
    "player_max_ap": 10
}
```

**字段说明**：

| 字段                             | 说明                                                 |
| ------------------------------ | -------------------------------------------------- |
| `act_id`                       | 技能 ID                                              |
| `apcost`/`cd`/`target`/`range` | 来自 skill\_config                                   |
| `lstact`                       | 来自 skillpara，上次使用的 tick                            |
| `current_tick`                 | 当前游戏刻（前端计算 CD 用）。注意：API内有其他钩子直接返回当前游戏刻，你不需要再自己创建一个 |
| `on_cd`                        | 是否在 CD 中（`current_tick - lstact < cd`）             |
| `available`                    | 是否可用（不在 CD 且 AP 足够）                                |
| `player_ap`/`player_max_ap`    | 玩家当前 AP 状态                                         |

## 八、执行流程

### 8.1 玩家首次预装填

```
1. 玩家点击已发现敌人
2. 前端切换为预装填界面（临时状态，action 仍为 null）
3. 前端调用 GET /api_v2.php?cmd=skill_list
4. 后端 skill_get_available_list() 返回技能列表
5. 前端渲染技能列表 + 装填区
6. 玩家点击技能 → 瞄准模式 → 选目标 → 加入队列
7. 玩家点击 [执行]
8. 前端 POST /command.php {command: obl_battle_start, enemy_pid, actions}
9. 后端 cmd_handle_obl_battle_start() → battle_main()
10. battle_main():
    - prepare: AP 恢复
    - verify: skill_act_verify() 校验每个动作
    - excute: obl_calc_damage() + battle_apply_damage() + skill_execute()
    - queue_check: 先攻队列管理
    - finish_check: 战斗结束检测
11. 后端返回结果
12. 前端播放 battle_log 动画
```

### 8.2 逃跑执行流程

```
1. 玩家在装填区选择 [逃跑]
2. target=self，直接加入队列
3. 玩家点击 [执行]
4. 后端 battle_main():
    - verify: skill_act_verify('escape') 通过
    - excute: 
        - obl_calc_damage() 返回 0（damage_type=none）
        - battle_apply_damage() 应用 0 伤害（无效果）
        - skill_execute() 调用 calc/escape.calc.php
        - escape_calc(): 随机 50%
            - 成功: battle_state_clear() + emit escape_success
            - 失败: emit escape_fail
    - finish_check: 若逃跑成功，战斗已结束
```

### 8.3 CD 检查流程

```
1. 玩家在装填区点击技能
2. 前端检查 on_cd 字段：
   - current_tick - lstact < cd → 在 CD 中，置灰不可选
   - 否则可选
3. 玩家加入队列并执行
4. 后端 skill_act_verify():
   - 查 config 获取 cd
   - 查 skillpara[act_id].lstact
   - current_tick - lstact >= cd → 通过
   - 通过后更新 lstact = current_tick
```
