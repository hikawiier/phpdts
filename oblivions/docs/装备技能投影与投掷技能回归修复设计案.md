# 装备技能投影与投掷技能回归修复设计案

## 一、问题

死代码清理删除了旧 `skill/modules/throw.skill.php`。该文件的大部分旧战斗校验和执行逻辑确已被新 Combat 技能钩子替代，但它还注册了仍在使用的装备技能注入器：装备投掷武器时向运行态 `skillpara` 注入 `throw`。

清理后 `skill.modules.php` 注册器仍存在，但没有任何 injector，导致：

```text
throwing_spear 已装备
  -> obl_format_playerdata
  -> skill_inject_equipment 空操作
  -> skillpara 无 throw
  -> skill_get_available_list 不返回 throw
  -> 前端装填区没有投掷技能
```

`combat_skill_config.php`、`skill_throw.php` 和前端文案均未丢失，问题只在技能拥有权投影层。

## 二、修复原则

不恢复 deprecated 旧模块。装备授予技能是技能身份与生命周期规则，应由 `skill_definition_config.php` 描述，并由 `skill.main.php` 通用投影。

装备技能定义增加 `equipment_grant`：

```php
'equipment_grant' => array(
    'slots' => array('wep', 'wep2'),
    'any_tags' => array('tag_weapon_throwing'),
    'any_kinds' => array('WC'),
),
```

任一声明槽位满足任一 Tag 或种类代码，即在格式化后的运行态 `skillpara` 中注入该技能。保存前仍由 `skill_strip_temporary()` 剥离，装备技能不成为永久技能。

## 三、边界

- 同时支持主武器和副武器。
- 优先使用模板 ID 的 Tag；保留 `WC` 运行时种类代码兼容自定义/缺失模板 ID 的装备实例。
- 普通武器不得获得 `throw`。
- 卸下投掷武器后，下次读取不会再注入 `throw`。
- 自定义模块 injector 机制继续保留，供无法由配置表达的未来装备技能使用。

## 四、验证

新增独立装备技能测试，不使用 `TestRoom::player()` 默认的“全技能 fixture”：

1. `throwing_spear` 主武器授予 `throw`。
2. `WC` 副武器授予 `throw`。
3. 普通 `rusty_pipe` 不授予 `throw`。
4. `skill_get_available_list()` 对投掷武器玩家输出 `throw`。
