## 二、缺失框架清单（设计案需要但代码不存在的）

### 2.1 后端 — 命令层缺失

| 缺失项 | 优先级 | 设计案依赖 | 说明 |
|--------|--------|-----------|------|
| `obl_use_item` 命令 | **P0** | 食物经验、药剂恢复、所有消耗品 | 游戏没有"使用道具"的能力。捡起来就放着了。这是烹饪→食物→经验链条的前提 |
| `obl_craft` 命令 | **P0** | 合成/制作系统 | 工作台交互入口 |
| `obl_cat_eat` / `obl_cat_vomit` | P1 | 猫背包机制 | 吞道具进肚子 / 吐毛球还原 |
| `obl_inspect` / `obl_interact` | P2 | 门验证、特殊物体交互 | 目前没有"查看/操作场景物体"的通用接口 |

### 2.2 后端 — 系统层缺失

| 缺失项 | 优先级 | 依赖 | 说明 |
|--------|--------|------|------|
| **合成/制作系统** | P0 | `obl_craft` + 配方表 + 工作台 POI | 核心循环。玩家收集素材 → 在工作台合成工具 → 用工具合成更高级物品 |
| **食物经验系统** | P0 | `obl_use_item` + 升级函数 | 食物提供经验，首次吃 100%、第二次 50%、第三次 10%、之后 0%。唯一经验来源 |
| **猫背包系统** | P1 | `obl_cat_eat/vomit` + 升级表 | 替代/扩展标准背包。猫仓储可升级（容量/保鲜/便携工作站） |
| **伙伴/同行系统** | P1 | Alice 入队后跟随 | 目前无敌对/中立 NPC 管理。Alice 作为 type>0 的特殊 NPC 存在 |

### 2.3 后端 — 内容层缺失

| 缺失项 | 优先级 | 类型 | 说明 |
|--------|--------|------|------|
| **兔子敌人类型** | P0 | enemy_config + pool | 初始教程敌人。有多变体（持剑/绅士/海盗） |
| **爱丽丝 Boss** | P1 | enemy_config + 特殊战斗逻辑 | 枪火击溃（打断玩家动作）、两段投降 |
| **千年虫 Boss** | P1 | enemy_config + 三阶段战场 | 代码里已有"千年虫"概念但无具体实现 |
| **蟑螂拟态事件** | P1 | is_trap 配置 + 包围事件 | 基础设施已有（`discovered=2`/`fake_item_id`/`is_trap`），缺具体道具和事件流 |
| **气球事件** | P2 | 地图事件 | 气球从天而降 → 外壳消失 → 露出爱丽丝 |
| **大门验证机关** | P2 | 特殊地图格交互 | 全息图显示、多人验证、权限模块验证 |
| **工作台 POI** | P0 | poi_table + mechanic | 合成系统的物理载体。不同等级工作台解锁不同配方 |
| **咖啡机 POI** | P2 | poi_table + mechanic | SP 恢复/增益 |

### 2.4 前端 — 组件/UI 缺失

| 缺失项 | 优先级 | 说明 |
|--------|--------|------|
| **合成 UI** | P0 | 素材列表、可用配方、合成按钮 |
| **道具使用 UI** | P0 | 背包中道具的"使用"按钮/右键菜单 |
| **对话框组件** | P1 | 剧情对话的气泡/模态框（猫说话、爱丽丝说话） |
| **猫背包 UI** | P1 | 猫肚子状态、升级面板 |
| **教程流程控制器** | P1 | 兔子四拍 → 逃跑 → 拿武器 → 返回的脚本化流程 |
| **Boss 打断 UI** | P1 | 爱丽丝拔枪时的视觉警示/提示 |
| **千年虫阶段切换** | P1 | 三战场场景过渡动画 |
| **大门验证交互** | P2 | 全息图、多人放置、权限扫描 |
| **结局过场** | P2 | 天幕消失 → 宇宙展开 → 飞船轮廓 → 上摇镜头 |
| **气球迷雾掉落** | P2 | 气球从空中坠落的视觉序列 |

### 2.5 前端 — 数据/类型缺失

## 三、按实施顺序的依赖链

### 第一阶段（P0 — 最小可玩沙盒）

```
obl_use_item 命令          ← 所有消耗品前置
  └→ 食物经验系统          ← 升级的核心驱动
obl_craft 命令             ← 合成的执行入口
  └→ 配方表 + 工作台 POI  ← 合成的数据 + 载体
      └→ 合成 UI          ← 前端合成界面
兔子敌人 + 四拍教程        ← 玩家第一个遭遇
```

**目标**：玩家能完成"捡素材 → 做武器/厨具 → 做饭吃 → 升级"的完整沙盒体验。

### 第二阶段（P1 — 第一幕完整流程）

```
蟑螂拟态事件              ← 教程宝箱怪
千年虫敌人 + 三阶段战斗    ← 伪 Boss/最终 Boss
爱丽丝 Boss + 枪打断      ← 入队战
猫背包系统                ← 核心伴侣机制
伙伴系统                  ← Alice 跟随
对话框组件                ← 剧情对话
教程流程控制器            ← 管理脚本化序列
```

**目标**：第一幕全部八场戏可从头到尾完整游玩。

### 第三阶段（P2 — 细节/打磨）

```
气球事件                  ← 爱丽丝出场
大门验证 + 全息图          ← 谜题交互
咖啡机 POI                ← 彩蛋
结局过场                  ← 第一幕结束
门后/收尾自由探索          ← 存档点
```

**目标**：第一幕的演出质量和细节密度达标。
