## 二、缺失框架清单（设计案需要但代码不存在的）

### 2.1 后端 — 命令层缺失

| 缺失项 | 优先级 | 设计案依赖 | 说明 |
|--------|--------|-----------|------|
| `obl_cat_eat` / `obl_cat_vomit` | P1 | 猫背包机制 | 吞道具进肚子 / 吐毛球还原 |
| `obl_inspect` / `obl_interact` | P2 | 门验证、特殊物体交互 | 目前没有"查看/操作场景物体"的通用接口 |

### 2.2 后端 — 系统层缺失

| 缺失项 | 优先级 | 依赖 | 说明 |
|--------|--------|------|------|
| **食物经验系统** | P0 | `obl_use_item`（已留 restore_sp 钩子） | 食物提供经验，首次吃 100%、第二次 50%、第三次 10%、之后 0%。唯一经验来源。需向 obl_use_item 注册 restore_sp 效果函数 |
| **Body Status Tag 系统** | P1 | `obl_use_item`（已留 cure_bs 钩子）+ oblpara JSON（已有）+ Tick 系统（已有） | bs_foot_hurt/bs_stomach_sick/bs_arm_numb/bs_charged 的存储/触发/衰减；需向 obl_use_item 注册 cure_bs 效果函数 |
| **鉴定系统** | P1 | `item_table.tags`（已有）+ 合成系统（已留介入点 2） | 未鉴定/已鉴定双形态；合成系统步骤 8 已预留鉴定介入点 |
| **猫背包系统** | P1 | `obl_cat_eat/vomit` + 升级表 | 替代/扩展标准背包。猫仓储可升级（容量/保鲜/便携工作站） |
| **伙伴/同行系统** | P1 | Alice 入队后跟随 | 目前无敌对/中立 NPC 管理。Alice 作为 type>0 的特殊 NPC 存在 |
| **被动技能系统** | P1 | `obl_use_item`（已留 gain_resistance 钩子） | 抗性跃迁机制依赖；需向 obl_use_item 注册 gain_resistance 效果函数 |
| **死亡复活系统** | P1 | battle_state_clear（已有） | 复活点绑定、死亡时道具丢弃存储（复用 bra_oblmapitem）、状态重置衔接 |
| **教程流程控制器** | P1 | 兔子敌人类型 + 对话框组件 | 管理脚本化序列（兔子四拍 → 逃跑 → 拿武器 → 返回） |
| **剧情导演层** | P1 | 对话节点类型 | 非战斗演出导演，对称于战斗的 `battle-director.ts`；把后端 emit 的扁平对话节点序列编排成 DialogScript |
| **环境击杀机制** | P2 | 战斗系统扩展 | 远古豆腐 Boss"不接触"击杀方式（环境击杀/引到特定区域/特殊道具） |

### 2.3 后端 — 内容层缺失

| 缺失项 | 优先级 | 类型 | 说明 |

| **咖啡机 POI** | P2 | poi_table + mechanic | SP 恢复/增益 |

## 三、按实施顺序的依赖链

### 第一阶段（P0 — 最小可玩沙盒）

**已完成**：
```
✅ obl_use_item 命令          ← 消耗品前置（纯分发器架构）
✅ obl_craft 命令             ← 合成的执行入口
✅ item_table.tags 字段       ← 道具性质 Tag
✅ recipe_table 配方表        ← 合成数据
✅ 工作台 POI                 ← 合成载体
✅ 合成/制作系统              ← 完整事务性合成
✅ 合成 UI + 道具使用 UI      ← 前端界面
✅ 配方/合成 TS 类型          ← 前端类型
```

**剩余**：
```
食物经验系统                  ← 需向 obl_use_item 注册 restore_sp 效果函数
兔子敌人 + 四拍教程           ← 玩家第一个遭遇（教程流程控制器的前置）
```

**目标**：玩家能完成"捡素材 → 做武器/厨具 → 做饭吃 → 升级"的完整沙盒体验。

### 第二阶段（P1 — 第一幕完整流程）

```
Body Status Tag 系统          ← 向 obl_use_item 注册 cure_bs（前置全满足）
鉴定系统                      ← 接入合成系统介入点 2（前置全满足）
死亡复活系统                  ← 扫雷案硬前置（前置 battle_state_clear 已有）
对话节点类型 + 对话框组件     ← 非战斗演出基础设施
剧情导演层                    ← 对称于 battle-director.ts
教程流程控制器                ← 前置：兔子敌人类型 + 对话框组件
蟑螂拟态事件                  ← 教程宝箱怪
千年虫敌人 + 三阶段战斗       ← 伪 Boss/最终 Boss
爱丽丝 Boss + 枪打断          ← 入队战
猫背包系统                    ← 核心伴侣机制
伙伴系统                      ← Alice 跟随
吃瘪看板娘视觉                ← Body Status 立绘表现
```

**目标**：第一幕全部八场戏可从头到尾完整游玩。

### 第三阶段（P2 — 细节/打磨）

```
气球事件                  ← 爱丽丝出场
大门验证 + 全息图          ← 谜题交互
咖啡机 POI                ← 彩蛋
结局过场                  ← 第一幕结束
被动技能系统              ← 抗性跃迁（资源案§4.2）
环境击杀机制              ← 远古豆腐 Boss
门后/收尾自由探索          ← 存档点
```

**目标**：第一幕的演出质量和细节密度达标。
