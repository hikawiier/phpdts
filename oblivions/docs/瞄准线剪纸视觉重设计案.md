# 瞄准线剪纸视觉重设计案

## 1. 目标

瞄准线从战斗操作面板的功能连线，改为玩家角色向地图目标发出的空间指向。视觉语言与角色立绘保持一致：白色主体、黑色描边、白色外轮廓，终点使用剪纸风格箭头。

## 2. 起点与终点

1. 起点取 `[data-entity-id="player"] .entity-img` 当前视口包围盒的水平中心、垂直 38% 位置，近似角色上半身发力点。
2. 若图片暂不可用，退回玩家 `.entity` 容器中心；不得退回 AP 槽或战斗操作栏。
3. 敌人目标取目标实体包围盒中心，格子目标取格子中心；自由移动时取鼠标位置。
4. 每次 mousemove 重新读取玩家立绘包围盒，因此地图缩放、平移及角色动画期间起点仍跟随角色。

## 3. 曲线

曲线使用双控制点三次贝塞尔，保留旧瞄准线算法的结构但取消“起点必在右侧 AP 栏”的方向假设。第一控制点位于路径 22% 处并承担主要法线偏移，第二控制点位于 72% 处且只保留四分之一偏移，使曲线从玩家侧略微挑起、接近目标时快速收直。该非对称结构比单控制点二次贝塞尔更直接，也保留轻微手工折势。

同一路径叠放三条完全同相位的虚线：

| 层 | 宽度 | 颜色 | 作用 |
|---|---:|---|---|
| 外层 | 7px | 白色 | 剪纸外轮廓，与暗背景分离 |
| 中层 | 5px | 黑色 | 角色立绘式黑边 |
| 主体 | 2px | 白色 | 实际方向线 |

三层使用相同的 `stroke-dasharray`、`stroke-dashoffset` 和圆形端帽，保证黑白关系存在于每一个独立纸片段，而不是三条错位虚线。

## 4. 终点箭头

1. 删除起点与终点红点。
2. 箭头由一段短箭身和两条箭翼开放路径组成，不使用实心多边形或规则 SVG marker 三角形。
3. 箭头尖端固定在目标坐标，整体按贝塞尔曲线末端切线角度旋转。
4. 箭头完整复用虚线段的 7px 白色外轮廓、5px 黑边、2px 白色主体三层描边和圆形端帽，使箭身、箭翼与每个虚线纸片拥有相同质感。
5. 箭头不参与点击，瞄准覆盖层继续保持 `pointer-events: none`。
6. 最终实机参数为 `trimDistance = min(23px, 路径距离 × 0.3)`。箭身从箭尖后 16px 开始；达到最大截断距离时，箭尾与虚线路径端点形成 7px 几何间隔，正好抵消两侧 7px 外描边圆形端帽各约 3.5px 的外扩。该参数让两者视觉上接近相连但不发生明显穿透，且短路径会按距离等比收缩截断量。不得继续把完整曲线画到箭尖后再用箭头覆盖，否则白色主体会产生贯穿箭头的错觉。

## 5. 动效与约束

1. 虚线保持低速向目标方向流动，表达瞄准尚未提交；箭头不做缩放呼吸，避免干扰目标识别。
2. `prefers-reduced-motion: reduce` 时关闭虚线位移动画。
3. 正式样式只保留在 `AimMode.vue`；删除旧 `#aimLineOverlay` 遗留样式，避免形成第二套视觉定义。
