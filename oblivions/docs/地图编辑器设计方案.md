# Oblivions 地图编辑器设计方案

> 版本：2.0 | 2026-06-14
> 定位：可视化编辑 Oblivions 区域地图的独立工具

---

## 一、定位与约束

| 项 | 值 |
|---|---|
| 部署形式 | Vite 前端项目，`npm install && npm run dev` 启动 |
| 保存方式 | 导出下载 `map.php` + `region_*.php`（ZIP 打包） |
| 导入方式 | 粘贴 PHP 文件内容解析加载，或直接拖入文件 |
| 视觉风格 | 剪纸风格（与 vex 前端一致） |
| 后端要求 | 无 PHP 依赖，纯前端工具 |

---

## 二、技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 构建 | Vite | 开发服务器 + 生产构建，零配置即用 |
| 语言 | 原生 ES Modules | 与 vex 前端保持一致，不引入框架 |
| 样式 | 原生 CSS3 | 复用 vex 剪纸风格变量，CSS Grid 布局 |
| ZIP 导出 | jszip（npm） | 生成含 map.php + region_*.php 的 ZIP 包 |
| 文件下载 | file-saver（npm） | 触发浏览器下载 |
| PHP 解析 | 自实现 php-array-parser | 解析 PHP 关联数组为 JSON |

**不引入的前端框架**：与项目 vex 前端保持一致的哲学——原生 JS + ES Modules，交互复杂度不需要虚拟 DOM。

---

## 三、数据模型

编辑器内存中维护的数据结构，与项目 PHP 数据模型一一对应：

```javascript
project = {
  regions: {
    [pgroup]: {
      name, desc, entrance_pls, exit_pls,
      next_region, prev_region, exit_links
    }
  },
  grids: {
    [pgroup]: { cols, rows }
  },
  tiles: {
    [pgroup]: {
      [pls]: {
        name, desc, floor, tide, height,
        passable, destructible, neighbors,
        x, y, preset_safe,
        // 编辑器专有：手动断开的连接
        _breaks: [pls, ...]   // 强制取消与这些格的自动连通
      }
    }
  }
}
```

## 五、核心功能

### 5.1 区域管理

| 操作 | 说明 |
|------|------|
| 新建区域 | 分配新 pgroup，设置名称/描述/网格尺寸 |
| 删除区域 | 确认后删除，清理其他区域的 next/prev 引用 |
| 区域属性编辑 | 名称、描述、网格尺寸（调整时保留已有格） |
| 出入口配置 | 下拉选择该区域内的地图格作为 entrance_pls / exit_pls |
| 区域连接 | 下拉选择 next_region / prev_region，自动双向同步 |

### 5.2 网格画布交互

**工具模式**：

| 工具 | 操作 | 快捷键 |
|------|------|--------|
| 选择 | 点击格选中，显示属性面板 | V |
| 绘制 | 点击空白格创建新地图格 | B |
| 擦除 | 点击格删除 | E |
| 断开连通 | 点击一格再点相邻格，强制断开两者连通 | D |
| 恢复连通 | 点击已断开的连接，恢复自动连通 | R |

**画布渲染规则**（与游戏前端一致）：

| 格状态 | 渲染样式 |
|--------|---------|
| 空白格 | 深灰底 + 虚线边框 |
| 入口格 | 绿色内边框 + "入" 标记 |
| 出口格 | 蓝色内边框 + "出" 标记 |
| 不可通行 | 黑色底 + 红色叉 |
| 当前选中 | 黄色高亮 + 粗边框 |
| 已断开连通的相邻格 | 红色虚线连接线 |

**连通关系可视化**：相邻格之间画连接线，已断开的画红色虚线，正常连通画绿色实线。

### 5.3 自动连通算法

```
放置/移动地图格时：
  1. 扫描8方向相邻坐标的所有格
  2. 对每个相邻格：
     a. 如果在 _breaks 列表中 → 跳过（保持断开）
     b. 否则 → 自动建立双向连通（双方 neighbors 互加）
  3. 删除格时 → 清理所有邻居的 neighbors 引用和 _breaks 引用

手动断开连通时：
  1. 将目标 pls 加入当前格的 _breaks
  2. 将当前格的 pls 加入目标格的 _breaks
  3. 从双方 neighbors 中移除对方

恢复连通时：
  1. 从双方 _breaks 中移除
  2. 重新加入双方 neighbors
```

### 5.4 地图格属性编辑

右栏属性面板，选中格后显示：

| 属性 | 控件 | 说明 |
|------|------|------|
| pls | 只读 | 区域内局部索引 |
| name | 文本输入 | 地图格名称 |
| desc | 文本域 | 描述文字 |
| floor | 下拉选择 | standard / water / vegetation / metal / magic |
| tide | 下拉选择 | shallow / deep / abyss / safe |
| passable | 复选框 | 是否可通行 |
| preset_safe | 复选框 | 是否预设安全区 |
| x, y | 只读/可调 | 坐标（拖拽移动时自动更新） |
| neighbors | 只读列表 | 显示连通关系，可点断开/恢复 |

### 5.5 导入功能

两种导入方式：

1. **粘贴导入**：点击"导入"按钮 → 弹出对话框，粘贴 `map.php` 和 `region_*.php` 内容
2. **拖拽文件**：直接将 PHP 文件拖入编辑器窗口，自动识别并解析

解析逻辑：自实现 `php-array-parser`，提取 `return [...]` 中的 PHP 数组结构转为 JSON。

### 5.6 导出功能

点击"导出全部" → 通过 jszip 生成 ZIP 文件下载，包含：

```
oblivions_gamedata.zip
├── map.php
└── tiles/
    ├── region_1.php
    └── region_2.php
```

**导出的 `map.php` 格式**：
```php
<?php
if (!defined('IN_GAME')) { exit('Access Denied'); }
return [
    'regions' => [ ... ],
    'grids' => [ ... ],
];
```

**导出的 `region_*.php` 格式**：
```php
<?php
if (!defined('IN_GAME')) { exit('Access Denied'); }
return [
    1 => [ 'name' => '...', ... ],
    ...
];
```

`_breaks` 字段不导出（编辑器专有），断开的连通关系通过 `neighbors` 中缺少对应项来体现。

## 六、技术实现要点

| 项 | 方案 |
|---|---|
| 画布渲染 | CSS Grid（与游戏前端一致），动态调整 `grid-template-columns/rows` |
| 连接线 | SVG 叠加层，绝对定位在网格上方 |
| PHP 解析 | `src/lib/php-array-parser.js` — 自实现 PHP 关联数组 → JSON 转换器 |
| PHP 生成 | `src/lib/php-codegen.js` — JSON → PHP 数组代码生成器（保持项目格式风格） |
| ZIP 导出 | jszip（npm 依赖） |
| 文件下载 | file-saver（npm 依赖） |
| 拖拽移动 | mousedown/mousemove/mouseup 事件，更新 x/y 坐标并重新计算连通 |
| 状态持久化 | localStorage 自动保存，刷新不丢失 |
| 开发服务器 | Vite dev server，HMR 热更新 |

## 八、与现有数据模型的映射

编辑器导出的数据直接对应 `oblivions/gamedata/` 下的文件结构：

| 编辑器数据 | 导出文件 | 项目中的消费方 |
|-----------|---------|--------------|
| `project.regions` + `project.grids` | `map.php` | `obl_get_map_data()` 首次加载 |
| `project.tiles[pgroup]` | `tiles/region_{pgroup}.php` | `obl_get_map_data($pgroup)` 按需加载 |
| `regions[pgroup].entrance_pls` / `exit_pls` | `map.php` 内 | `obl_move()` 区域切换逻辑 |
| `tiles[pgroup][pls].neighbors` | `region_*.php` 内 | 前端 `isReachable()` + 后端 `obl_move()` 连通判定 |
| `tiles[pgroup][pls].x` / `.y` | `region_*.php` 内 | 前端 `renderMapGrid()` 坐标定位 |
