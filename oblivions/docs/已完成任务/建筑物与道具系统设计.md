# Oblivions 地图资源生成 — 建筑物与道具系统设计

> 版本：3.0 | 2026-06-14
> 基于 v2.0 调整：POI 无近视机制（仅由迷雾控制可见性）；道具近视类似拟态怪（拾取才揭示）；新增原地探索命令；玩家出生点自动点亮迷雾；可重复搜索建筑物增加冷却/次数限制

---

## 一、核心流程

```
游戏初始化
  └── 按潮汐属性在地图格上生成野生道具(iaid=0)和建筑物 → 分别存入 bra_oblmapitem / bra_oblmappoi
        │
        ▼
玩家出生点自动点亮迷雾
  └── 更新 bra_oblmapstates.fog=1 → 出生格及视野范围内所有格迷雾清除
        │
        ▼
玩家移动到某格 / 原地探索
  └── 自动触发探索 → 后端结算探索：
      ├── 点亮迷雾（bra_oblmapstates.fog=1）
      ├── 发现 iaid=0 的道具（bra_oblmapitem.discovered 更新）
      └── 发现建筑物（迷雾清除即可见，无需 discovered 字段）
        │
        ▼
玩家搜索建筑物
  └── 后端结算搜索：
      ├── 机制触发型（图腾等）：触发效果（回血/学技能），无道具掉落
      ├── 掉落型：按掉落表生成道具 → bra_oblmapitem (discovered=1)
      └── 可重复搜索型：按冷却/次数限制判定是否可再搜
        │
        ▼
玩家拾取道具
  └── 道具从 bra_oblmapitem 删除 → 进入玩家背包
      └── 近视道具(discovered=2)：拾取时才揭示真实身份（可能是同级/更高级/伪装怪物）
```

**关键设计**：
- 道具在初始化时生成野生道具(iaid=0)，搜索建筑物时按需生成建筑道具(iaid>0)
- POI 无近视机制，可见性完全由迷雾(bra_oblmapstates.fog)控制
- 道具近视类似拟态怪：靠近不会揭示，必须拾取才能发现真实身份
- 原地探索是独立命令，与移动分离，移动也会自动触发探索

### 2.2 掉落表字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `item_id` | string | 关联 item_table.php 的道具模板 ID |
| `count` | int 或 [min,max] | 掉落数量。int 固定数量，数组随机范围 |
| `rate` | float | 掉落概率（0-1），每条独立判定 |

**判定逻辑**：遍历掉落表，每条独立按 `rate` 判定是否掉落。一次搜索可能掉落 0~N 种道具。

### 2.3 建筑物模板字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 建筑物名称 |
| `desc` | string | 搜索时显示的描述文本 |
| `tide` | string | 限定生成在哪种潮汐区：shallow/deep/abyss |
| `per_region` | int | 每区域生成数量 |
| `searchable` | bool | 是否可搜索。false = 纯视觉标记（如地标） |
| `repeatable` | bool | 是否可重复搜索 |
| `repeat_limit` | int | [可选] 最大搜索次数，0=无限。仅 repeatable=true 时有效 |
| `repeat_cooldown` | int | [可选] 重复搜索冷却回合数，0=无冷却。仅 repeatable=true 时有效 |
| `loot` | array | 首次搜索掉落表 |
| `repeat_loot` | array | [可选] 重复搜索掉落表。不设则 repeatable=false 的建筑物无此字段 |
| `mechanic` | string | [可选] 搜索时触发的特殊机制标识（如回血、学技能） |
| `mechanic_value` | mixed | [可选] 机制参数值 |
| `mechanic_params` | array | [可选] 机制参数列表 |

## 三、数据库表

### 3.1 bra_oblmappoi — POI实例

```sql
DROP TABLE IF EXISTS bra_oblmappoi;
CREATE TABLE bra_oblmappoi (
  iaid mediumint unsigned NOT NULL auto_increment,
  pgroup tinyint unsigned NOT NULL default '0',
  pls tinyint unsigned NOT NULL default '0',
  poi_id varchar(32) NOT NULL default '',
  searched tinyint(1) unsigned NOT NULL default '0',
  search_count tinyint unsigned NOT NULL default '0',
  last_search_turn int unsigned NOT NULL default '0',

  PRIMARY KEY (iaid),
  INDEX idx_pgroup_pls (pgroup, pls)
) ENGINE=MyISAM DEFAULT CHARSET=utf8mb4;
```

| 字段 | 说明 |
|------|------|
| `iaid` | 自增主键 |
| `pgroup` + `pls` | 建筑物所在地图格 |
| `poi_id` | 关联 poi_table.php 的建筑物模板 ID |
| `searched` | 是否已被搜索过（0=未搜索, 1=已搜索） |
| `search_count` | 累计搜索次数（repeatable 建筑物可 >1） |
| `last_search_turn` | 上次搜索时的回合数（用于冷却计算） |

**POI 可见性说明**：POI 无 `discovered` 字段，其可见性完全由地图格迷雾状态（bra_oblmapstates.fog）决定。迷雾清除时，该格上所有 POI 自动可见。

### 3.2 bra_oblmapitem — 地图道具实例

已创建，见 [oblivions/sql/oblmapitem.sql](oblivions/sql/oblmapitem.sql)。

| 字段 | 说明 |
|------|------|
| `iid` | 自增主键 |
| `pgroup` + `pls` | 道具所在地图格 |
| `iaid` | 关联POI实例 ID。0=非建筑物来源（如敌人掉落），>0=属于该建筑物 |
| `item_id` | 关联 item_table.php 的道具模板 ID（真实道具） |
| `itm/itmk/itme/itms/itmsk/itmpara` | 冗余存储实例属性，与现有物品字段格式一致 |
| `discovered` | 发现状态：0=未发现, 1=已发现, 2=近视 |
| `fake_item_id` | 近视时显示的假道具 ID。空=显示真实名称+(?)，非空=显示该道具的名称+(?) |
| `is_trap` | 是否为伪装陷阱（0=正常道具, 1=拾取时触发战斗） |

**iaid 归属规则**：
- 搜索建筑物时生成的道具，`iaid = 该建筑物的iaid`，道具始终属于该建筑物直到被拾取
- 非建筑物来源的道具（如敌人掉落/野生道具），`iaid = 0`，前端显示在「就在脚边...」中
- 前端无需维护临时归属状态，API 按 iaid 分组返回数据

### 3.3 bra_oblmapstates — 图格状态

```sql
DROP TABLE IF EXISTS bra_oblmapstates;
CREATE TABLE bra_oblmapstates (
  pgroup tinyint unsigned NOT NULL,
  pls tinyint unsigned NOT NULL default '0',
  fog tinyint(1) unsigned NOT NULL default '0',
  damaged tinyint(1) unsigned NOT NULL default '0',
  flags varchar(255) NOT NULL default '',

  PRIMARY KEY (pgroup, pls)
) ENGINE=MyISAM DEFAULT CHARSET=utf8mb4;
```

| 字段 | 说明 |
|------|------|
| `pgroup` + `pls` | 组合主键，唯一确定一个地图格 |
| `fog` | 迷雾状态（0=未探索, 1=已探索） |
| `damaged` | 破坏状态（0=完好, 1=被破坏） |
| `flags` | 扩展状态标记（JSON，预留编辑/特殊效果等） |

**设计说明**：
- Oblivions 是单人模式，不需要 uid 字段
- 迷雾仅影响可见性——迷雾中的格看不到建筑物和道具，但不阻挡搜索（玩家可以搜索已知位置的建筑物）
- 探索视野在移动时自动计算并更新
- 玩家出生时，出生格及视野范围内所有格自动点亮迷雾（fog=1）
- `flags` 为 JSON 字符串，可存储任意扩展状态，如 `{"edited":true,"trap":"poison"}`

### 3.4 discovered 三态（仅道具）

仅道具（bra_oblmapitem）使用 `discovered` 字段，POI 不使用此字段。

| 值 | 含义 | 前端表现 |
|---|------|---------|
| 0 | 未发现（迷雾中） | 不显示 |
| 1 | 已发现（正常可见） | 显示完整信息（名称/属性/描述） |
| 2 | 近视（模糊可见） | 显示"道具名（？）"或假名，看不到真实属性 |

**近视道具 = 拟态怪机制**：
- 近视道具**靠近不会揭示真实身份**，discovered 不会从 2 升级为 1
- 必须**拾取**才能发现真实身份：
  - `is_trap=0`：获得真实道具（可能是同级/更高级道具，与显示名称不同）
  - `is_trap=1`：触发战斗（伪装怪物），不获得道具
- 近视道具在动作条/弹窗中显示为"道具名（？）"，名称来自 `fake_item_id`（为空则用真实名称+（？））
- 近视道具**可以拾取**，拾取时后端揭示真实身份并返回结果

**不需要探索记忆系统**：道具的可见性由 `discovered` 字段控制，POI 的可见性由迷雾控制，无需额外的记忆表。

## 四、生成算法

### 4.1 建筑物生成（初始化时）

```
obl_generate_region_pois($pgroup):
  1. 读取 poi_table.php
  2. 读取该区域所有地图格，按 tide 分组
  3. 对每个建筑物模板:
     a. 按 tide 限制筛选候选格
     b. 排除已有建筑物的格
     c. 随机选择 per_region 个格
     d. 插入 bra_oblmappoi（searched=0, search_count=0, last_search_turn=0）
```

### 4.2 野生道具生成（初始化时）

初始化时按潮汐属性在地图格上生成野生道具（iaid=0），玩家探索时可直接发现：

```
obl_generate_wild_items($pgroup):
  1. 读取 item_table.php 中的野生道具配置
  2. 按潮汐区分配候选格
  3. 对每个野生道具模板:
     a. 随机选择地图格
     b. 实例化道具（复制模板属性）
     c. 插入 bra_oblmapitem（iaid=0, discovered=0）
     d. 若为近视道具，设置 fake_item_id / is_trap
```

### 4.3 道具生成（搜索建筑物时）

```
obl_search_poi($iaid, &$pdata):
  1. 从 bra_oblmappoi 读取POI实例
  2. 检查 searchable == true，否则提示"无法搜索"
  3. 检查 repeatable 或 searched == 0
  4. 若 repeatable == true:
     a. 检查 repeat_limit > 0 且 search_count >= repeat_limit → 提示"已达搜索上限"
     b. 检查 repeat_cooldown > 0 且 (当前回合 - last_search_turn) < repeat_cooldown → 提示"冷却中"
  5. 选择掉落表:
     - search_count == 0 → 使用 loot
     - search_count > 0  → 使用 repeat_loot（若无则不可再搜）
  6. 遍历掉落表，每条独立按 rate 判定:
     a. 判定成功 → 从 item_table.php 读取模板
     b. 实例化道具（复制 itm/itmk/itme/itms/itmsk/itmpara）
     c. 插入 bra_oblmapitem（pgroup=建筑物pgroup, pls=建筑物pls, iaid=建筑物iaid, discovered=1）
  7. 触发 mechanic（如有）：
     - 机制触发型POI（图腾等）：执行机制效果（回血/学技能），无道具掉落
  8. 更新 bra_oblmappoi: searched=1, search_count++, last_search_turn=当前回合
  9. 写日志"你搜索了{建筑物名称}……"
```

### 4.4 掉落实例化

从模板生成实例时，直接复制模板属性到 bra_oblmapitem：


## 五、探索与迷雾

### 5.1 迷雾规则

- **迷雾仅影响可见性**，不阻挡操作。玩家可以搜索已知位置的建筑物，但迷雾中看不到它
- 移动到某格时，自动触发探索，计算视野并点亮周围格的迷雾
- 原地探索（点击当前格）也会触发探索，效果同移动
- 点亮迷雾时，该格上所有 POI 自动可见（POI 无 discovered 字段，由迷雾决定可见性）
- 点亮迷雾时，该格上的道具根据距离设置 `discovered`：近处=1（正常可见），远处=2（近视）
- **玩家出生时**，出生格及视野范围内所有格自动点亮迷雾

### 5.2 视野计算

```
obl_update_vision($pgroup, $pls):
  1. 获取探索视野等级 vision_lv（默认1）
  2. 以当前格为中心，计算视野范围内的所有格:
     - lv1: 脚下 + 相邻格（neighbors）
     - lv2: 扩展到2格距离
     - lv3: 扩展到3格距离
  3. 对视野范围内的格:
     a. 插入/更新 bra_oblmapstates（fog=1）
     b. POI 可见性：迷雾清除后该格上所有 POI 自动可见（无需额外操作）
     c. 更新 bra_oblmapitem.discovered（该格上的道具）:
        - 脚下格: discovered=1
        - 相邻格: discovered=1
        - 视野边缘格: discovered=2（近视，拟态怪机制）
```

### 5.3 探索命令

探索有两种触发方式，后端结算逻辑相同：

| 触发方式 | 说明 |
|---------|------|
| 移动到某格 | 自动触发探索，移动+探索一步完成 |
| 原地探索 | 玩家点击/轻触当前格，独立触发探索命令 |

**原地探索的意义**：玩家可能在同一格停留多个回合（搜索建筑物、拾取道具后），原地探索可以发现当前格新出现的道具或变化。

### 5.4 近视道具机制

近视道具采用**拟态怪**设计——靠近不会揭示真相，必须拾取：

- `discovered=2` 的道具在动作条/弹窗中显示为"道具名（？）"，名称来自 `fake_item_id`（为空则用真实名称+（？））
- 近视道具**靠近不会升级为 discovered=1**，discovered=2 是其固定状态
- 近视道具**可以拾取**，拾取时后端揭示真实身份：
  - `is_trap=0`：获得真实道具（可能与显示名称不同，同级/更高级）
  - `is_trap=1`：触发战斗（伪装怪物），不获得道具
- 拾取后日志显示真实结果："你拾取了废铁片" 或 "那是一个陷阱！战斗开始！"

## 六、前端交互设计

前端交互设计已独立为单独文档，见 [前端交互设计.md](前端交互设计.md)。

核心要点：
- 底部动作条（Tile Action Bar）作为当前格统一互动入口，独立模块 `tile-action.js`
- 原地探索命令：点击当前格触发探索，与移动分离
- 搜索弹窗（Bottom Sheet）展示掉落列表，支持逐个/全部拾取
- 机制触发型POI搜索后显示效果而非道具列表
- 可重复搜索POI显示冷却/次数状态
- 模块间通过 DebugBus 事件通信，map.js 不依赖 tile-action.js
