# Oblivions 探索与交互系统设计

> 版本：2.0 | 2026-06-15
> 实现探索、搜索、拾取、丢弃全链路，打通玩家与 Oblivions 世界的核心交互闭环

---

## 一、设计目标

将 Oblivions 模式从"能移动"推进到"能玩"——玩家可以探索地图、搜索建筑物获取道具、拾取道具到背包、丢弃道具。这是最小可玩循环的核心。

**本次范围**：
- 探索系统（迷雾点亮 + 道具发现 + 体力检查 + 记忆范围）
- 搜索建筑物（掉落表结算 + 机制触发）
- 拾取道具（近视揭示 + 写入背包）
- 丢弃道具（背包→地图格）
- 移动体力检查（独立函数抽取）
- 命令路由集成
- API 接口
- 前端 tile-action.js 模块

**不在本次范围**：
- 敌人系统 / 战斗集成
- 游戏刻驱动（obl_tick）
- 可重复搜索冷却判定（简化：可无限重复搜索）
- is_trap 伤害/战斗触发（简化：仅写日志，不造成伤害）

---

## 二、玩家生命周期

```
0. 地图初始化，所有格子被迷雾覆盖
1. 玩家出生，所在格默认点亮；如有 POI 则显示在界面上
2. 玩家只能执行唯一动作——探索（因为其他格被迷雾覆盖）
3. 探索的结构：
   3.0 体力检查（独立函数，配置驱动，基础值 0 不消耗）
   3.1 根据视野范围属性点亮迷雾（配置驱动，基础值 1）
   3.2 根据记忆范围属性发现道具（配置驱动，基础值 3，随机抽取）
   3.3 探索后钩子（预留）
4. 玩家可以拾取已发现的道具
   4.1 玩家可以丢弃背包里的道具（掉落到当前格）
5. 玩家可以与 POI 交互
   5.1 搜索 POI，执行道具池生成
6. 玩家可以移动
7. 移动的结构：
   7.0 体力检查（独立函数，配置驱动，基础值 0 不消耗）
   7.1 移动逻辑（与当前代码一致）
   7.2 移动后自动探索，但不执行探索体力检查
```

```php
<?php
if (!defined('IN_GAME')) { exit('Access Denied'); }

return [
    // 探索

    'memory_range'     => 3,    // 每次探索最多发现的道具数量

```

**设计原则**：
- 所有可调参数集中管理，函数内部不硬编码
- 预留配置接口，未来由技能/装备动态覆盖时，只需修改读取逻辑（如从 `$pdata` 读取加成），配置文件不变

## 四、后端函数设计

### 4.1 obl_update_vision() — 视野更新（入口函数）

迷雾和道具发现是两个独立关注点：

| 关注点 | 作用域 | 数据表 | 状态 | 含义 |
|--------|--------|--------|------|------|
| 迷雾（fog） | 地图格可见性 | bra_oblmapstates | 0/1 | 玩家是否知道这个格的存在、地形、可通行性 |
| 道具发现（discovered） | 道具可操作性 | bra_oblmapitem | 0/1/2 | 道具是否出现在玩家的交互界面上 |

**为什么要分开**：
- 迷雾是地图知识（"这里有什么地形"），道具发现是交互可用性（"我能操作这个道具吗"）
- POI 可见性由迷雾决定，道具可见性由 discovered 决定——两套不同规则
- 未来可能出现"迷雾已清但道具仍不可见"（隐藏技能遮蔽）或"迷雾未清但道具可感知"（发光道具穿透迷雾）的场景
- discovered=2 的近视判定依赖距离，而迷雾是全量点亮——逻辑维度不同

`obl_update_vision()` 作为统一入口，内部调用两个子函数：

```php
/**
 * 视野更新入口：点亮迷雾 + 发现道具
 * 由移动后钩子或原地探索命令调用
 *
 * @param int   $pgroup 当前区域
 * @param int   $pls    当前格
 * @param array &$pdata 玩家数据
 */
function obl_update_vision($pgroup, $pls, &$pdata) {
    // 计算视野范围（BFS）
    $visible_tiles = obl_calc_vision_range($pgroup, $pls, $pdata);

    // 子功能 1：点亮迷雾（地图格可见性）
    obl_clear_fog($pgroup, $visible_tiles);

    // 子功能 2：发现道具（道具可操作性）
    obl_discover_items($pgroup, $visible_tiles);
}
```

### 4.1a obl_calc_vision_range() — 视野范围计算

```php
/**
 * 计算玩家视野范围内的所有格及其距离
 *
 * @param int   $pgroup 当前区域
 * @param int   $pls    当前格
 * @param array &$pdata 玩家数据（读取视野等级等）
 * @return array [pls => ['distance' => int]]
 */
function obl_calc_vision_range($pgroup, $pls, &$pdata) {
    $obl_config = include GAME_ROOT . './oblivions/gamedata/obl_config.php';
    $vision_lv = (int)($obl_config['vision_range'] ?? 1);

    $map = obl_get_map_data($pgroup);
    $tiles = $map['tiles'][$pgroup] ?? [];
    if (!isset($tiles[$pls])) return [];

    $visible_tiles = [];
    $visible_tiles[$pls] = ['distance' => 0];

    // BFS 扩展视野
    $visited = [$pls => true];
    $queue = [[$pls, 0]];
    while (!empty($queue)) {
        [$cur, $dist] = array_shift($queue);
        if ($dist >= $vision_lv) continue;

        $neighbors = $tiles[$cur]['neighbors'] ?? [];
        foreach ($neighbors as $n_pls) {
            if (isset($visited[$n_pls])) continue;
            if (empty($tiles[$n_pls]['passable'])) continue;
            $visited[$n_pls] = true;
            $visible_tiles[$n_pls] = ['distance' => $dist + 1];
            $queue[] = [$n_pls, $dist + 1];
        }
    }

    return $visible_tiles;
}
```

### 4.1b obl_clear_fog() — 迷雾点亮

```php
/**
 * 点亮视野范围内所有格的迷雾
 * 迷雾 = 地图格可见性：玩家是否知道这个格的存在、地形、可通行性
 * 迷雾清除后，该格上的 POI 自动可见（POI 无 discovered 字段）
 *
 * @param int   $pgroup       当前区域
 * @param array $visible_tiles [pls => ['distance' => int]]
 */
function obl_clear_fog($pgroup, $visible_tiles) {
    global $db, $tablepre;

    if (empty($visible_tiles)) return;

    $pgroup_i = (int)$pgroup;
    $fog_values = [];
    foreach ($visible_tiles as $t_pls => $info) {
        $t_pls = (int)$t_pls;
        $fog_values[] = "($pgroup_i, $t_pls, 1, 0, '')";
    }

    // INSERT ... ON DUPLICATE KEY UPDATE fog=1（幂等）
    $qry = "INSERT INTO {$tablepre}oblmapstates (pgroup, pls, fog, damaged, flags)
            VALUES " . implode(',', $fog_values) . "
            ON DUPLICATE KEY UPDATE fog=1";
    $db->query($qry);
}
```

### 4.1c obl_discover_items() — 道具发现（记忆范围随机抽取）

```php
/**
 * 根据记忆范围，从视野内未发现道具中随机抽取 N 个设为 discovered
 * discovered = 道具可操作性：道具是否出现在玩家的交互界面上
 *
 * 规则：
 * - 每次探索动作最多发现 memory_range 个道具（配置项，基础值 3）
 * - 从视野范围内所有 discovered=0 的道具中随机抽取
 * - 距离 <= 1（脚下+相邻格）→ discovered=1（正常可见）
 * - 距离 > 1（视野边缘格）→ discovered=2（近视/拟态怪）
 * - 仅更新 discovered=0 的道具（已发现的不降级）
 * - 同一格重复探索可继续发现剩余未发现道具
 *
 * @param int   $pgroup       当前区域
 * @param array $visible_tiles [pls => ['distance' => int]]
 */
function obl_discover_items($pgroup, $visible_tiles) {
    global $db, $tablepre;

    if (empty($visible_tiles)) return;

    $obl_config = include GAME_ROOT . './oblivions/gamedata/obl_config.php';
    $memory_range = (int)($obl_config['memory_range'] ?? 3);

    $pgroup_i = (int)$pgroup;

    // 1. 查询视野范围内所有未发现道具
    $pls_list = implode(',', array_map('intval', array_keys($visible_tiles)));
    $result = $db->query("SELECT iid, pls FROM {$tablepre}oblmapitem
                           WHERE pgroup='$pgroup_i' AND pls IN ($pls_list) AND discovered=0");

    $undiscovered = [];
    while ($row = $db->fetch_array($result)) {
        $undiscovered[] = [
            'iid' => (int)$row['iid'],
            'pls' => (int)$row['pls'],
        ];
    }

    if (empty($undiscovered)) return;

    // 2. 随机抽取 memory_range 个
    shuffle($undiscovered);
    $to_discover = array_slice($undiscovered, 0, $memory_range);

    // 3. 按距离分组更新 discovered 状态
    $d1_iids = [];  // discovered=1
    $d2_iids = [];  // discovered=2

    foreach ($to_discover as $item) {
        $distance = $visible_tiles[$item['pls']]['distance'] ?? 999;
        if ($distance <= 1) {
            $d1_iids[] = $item['iid'];
        } else {
            $d2_iids[] = $item['iid'];
        }
    }

    // discovered=1：脚下和相邻格的道具
    if (!empty($d1_iids)) {
        $iid_list = implode(',', $d1_iids);
        $db->query("UPDATE {$tablepre}oblmapitem
                     SET discovered=1
                     WHERE iid IN ($iid_list)");
    }

    // discovered=2：视野边缘格的道具（近视/拟态怪）
    if (!empty($d2_iids)) {
        $iid_list = implode(',', $d2_iids);
        $db->query("UPDATE {$tablepre}oblmapitem
                     SET discovered=2
                     WHERE iid IN ($iid_list)");
    }
}
```

### 4.2 obl_check_explore_sp() — 探索体力检查

```php
/**
 * 检查玩家是否满足探索消耗的体力
 * 独立函数，便于移动后自动探索时跳过
 *
 * @param array &$pdata 玩家数据
 * @return bool true=体力充足，false=体力不足
 */
function obl_check_explore_sp(&$pdata) {
    global $log;

    $obl_config = include GAME_ROOT . './oblivions/gamedata/obl_config.php';
    $cost = (int)($obl_config['explore_sp_cost'] ?? 0);

    if ($pdata['sp'] < $cost) {
        $log .= '体力不足，无法探索。<br>';
        return false;
    }

    // 扣除体力
    $pdata['sp'] -= $cost;
    return true;
}
```

### 4.3 obl_explore() — 探索命令

```php
/**
 * 探索当前格：体力检查 → 点亮迷雾 → 发现道具 → 探索后钩子
 *
 * @param array &$pdata          玩家数据
 * @param bool  $skip_sp_check   是否跳过体力检查（移动后自动探索时为 true）
 */
function obl_explore(&$pdata, $skip_sp_check = false) {
    global $log;

    // 1. 体力检查（移动后自动探索跳过）
    if (!$skip_sp_check) {
        if (!obl_check_explore_sp($pdata)) {
            return;
        }
    }

    $pgroup = (int)$pdata['pgroup'];
    $pls = (int)$pdata['pls'];

    // 2. 更新视野（迷雾点亮 + 道具发现）
    obl_update_vision($pgroup, $pls, $pdata);

    // 3. 探索日志
    $log .= "你仔细观察了周围的环境。<br>";

    // 4. 探索后钩子
    obl_post_explore_hook($pdata);
}
```

### 4.5 obl_search_poi() — 搜索建筑物

```php
/**
 * 搜索建筑物：掉落表结算 + 机制触发
 *
 * @param int   $iaid   建筑物实例 ID
 * @param array &$pdata 玩家数据
 */
function obl_search_poi($iaid, &$pdata) {
    global $db, $tablepre, $log;

    $iaid = (int)$iaid;
    $cur_pgroup = (int)$pdata['pgroup'];
    $cur_pls = (int)$pdata['pls'];

    // 1. 读取 POI 实例
    $result = $db->query("SELECT * FROM {$tablepre}oblmappoi WHERE iaid='$iaid'");
    if (!$db->num_rows($result)) {
        $log .= '找不到这个建筑物。<br>';
        return;
    }
    $poi = $db->fetch_array($result);

    // 2. 位置检查：只能搜索当前格的建筑物
    if ($poi['pgroup'] != $cur_pgroup || $poi['pls'] != $cur_pls) {
        $log .= '你不在那个建筑物旁边。<br>';
        return;
    }

    // 3. 载入 POI 模板
    $poi_table = include GAME_ROOT . './oblivions/gamedata/poi_table.php';
    $poi_id = $poi['poi_id'];
    if (!isset($poi_table[$poi_id])) {
        $log .= '建筑物数据异常。<br>';
        return;
    }
    $template = $poi_table[$poi_id];

    // 4. 可搜索检查
    if (empty($template['searchable'])) {
        $log .= "{$template['name']}无法搜索。<br>";
        return;
    }

    // 5. 重复搜索检查（v1 简化：不检查冷却，允许无限重复搜索）
    // 后续版本在此加入 repeat_limit / repeat_cooldown 判定

    // 6. 选择掉落表
    $poi_loot = include GAME_ROOT . './oblivions/gamedata/poi_loot.php';
    $loot_config = isset($poi_loot[$poi_id]) ? $poi_loot[$poi_id] : [];

    $is_repeat = !empty($poi['searched']);
    $loot_table = [];

    if ($is_repeat && isset($loot_config['repeat_loot'])) {
        $loot_table = $loot_config['repeat_loot'];
    } elseif (!$is_repeat && isset($loot_config['loot'])) {
        $loot_table = $loot_config['loot'];
    } elseif ($is_repeat && !isset($loot_config['repeat_loot'])) {
        // 一次性建筑物已搜索过
        $log .= "你已经搜索过{$template['name']}了。<br>";
        return;
    }

    // 7. 机制触发型 POI
    if (!empty($template['mechanic'])) {
        obl_execute_mechanic($template, $pdata);
    }

    // 8. 掉落表结算
    $item_table = include GAME_ROOT . './oblivions/gamedata/item_table.php';
    $dropped_items = [];

    foreach ($loot_table as $drop) {
        if (mt_rand() / mt_getrandmax() > $drop['rate']) continue;

        $item_id = $drop['item_id'];
        if (!isset($item_table[$item_id])) continue;

        $count = is_array($drop['count'])
            ? rand($drop['count'][0], $drop['count'][1])
            : (int)$drop['count'];

        for ($i = 0; $i < $count; $i++) {
            $tpl = $item_table[$item_id];
            $itm = $db->escape_string($tpl['itm']);
            $itmk = $db->escape_string($tpl['itmk']);
            $itme = (int)$tpl['itme'];
            $itms = (int)$tpl['itms'];
            $itmsk = $db->escape_string($tpl['itmsk']);
            $itmpara = $db->escape_string($tpl['itmpara']);

            $db->query("INSERT INTO {$tablepre}oblmapitem
                        (pgroup, pls, iaid, item_id, itm, itmk, itme, itms, itmsk, itmpara, discovered, fake_item_id, is_trap)
                        VALUES ('$cur_pgroup', '$cur_pls', '$iaid', '$item_id', '$itm', '$itmk', '$itme', '$itms', '$itmsk', '$itmpara', 1, '', 0)");

            $dropped_items[] = $tpl['itm'];
        }
    }

    // 9. 更新 POI 状态
    $new_count = (int)$poi['search_count'] + 1;
    $db->query("UPDATE {$tablepre}oblmappoi
                SET searched=1, search_count='$new_count'
                WHERE iaid='$iaid'");

    // 10. 日志
    if (!empty($template['mechanic'])) {
        $log .= "你搜索了{$template['name']}……<br>";
        // 机制效果日志由 obl_execute_mechanic 写入
    } elseif (!empty($dropped_items)) {
        $item_names = implode('、', array_unique($dropped_items));
        $log .= "你搜索了{$template['name']}，发现了<span class=\"yellow\">{$item_names}</span>。<br>";
    } else {
        $log .= "你搜索了{$template['name']}，但什么也没找到。<br>";
    }
}
```

### 4.6 obl_execute_mechanic() — 机制分发框架

```php
/**
 * 执行 POI 机制效果（通用分发框架）
 *
 * @param array $template POI 模板配置
 * @param array &$pdata   玩家数据
 */
function obl_execute_mechanic($template, &$pdata) {
    global $log;

    $mechanic = $template['mechanic'];

    // 分发到具体处理函数
    $handler = 'obl_mechanic_' . $mechanic;
    if (function_exists($handler)) {
        $handler($template, $pdata);
    } else {
        $log .= "机制【{$mechanic}】尚未实现。<br>";
    }
}

/**
 * 机制：增加最大生命值
 */
function obl_mechanic_max_hp_up($template, &$pdata) {
    global $log;

    $value = (int)($template['mechanic_value'] ?? 0);
    if ($value <= 0) return;

    $pdata['mhp'] += $value;
    // 同时回复等量生命值
    $pdata['hp'] = min($pdata['hp'] + $value, $pdata['mhp']);

    $log .= "一股暖流涌入体内，<span class=\"yellow\">最大生命值 +{$value}</span>！<br>";
    $log .= "当前生命：<span class=\"yellow\">{$pdata['hp']}/{$pdata['mhp']}</span><br>";
}
```

### 4.7 obl_pickup_item() — 拾取道具

```php
/**
 * 从地图拾取道具到背包
 *
 * @param int   $iid    道具实例 ID（bra_oblmapitem.iid）
 * @param array &$pdata 玩家数据
 */
function obl_pickup_item($iid, &$pdata) {
    global $db, $tablepre, $log;

    $iid = (int)$iid;
    $cur_pgroup = (int)$pdata['pgroup'];
    $cur_pls = (int)$pdata['pls'];

    // 1. 读取道具实例
    $result = $db->query("SELECT * FROM {$tablepre}oblmapitem WHERE iid='$iid'");
    if (!$db->num_rows($result)) {
        $log .= '找不到这个道具。<br>';
        return;
    }
    $item = $db->fetch_array($result);

    // 2. 位置检查
    if ($item['pgroup'] != $cur_pgroup || $item['pls'] != $cur_pls) {
        $log .= '那个道具不在你身边。<br>';
        return;
    }

    // 3. 发现状态检查（未发现的道具不能拾取）
    if (empty($item['discovered'])) {
        $log .= '你不知道那里有什么。<br>';
        return;
    }

    // 4. 近视道具揭示
    $real_itm = $item['itm'];
    $was_nearsighted = ($item['discovered'] == 2);

    if ($was_nearsighted) {
        // 揭示真实身份
        if (!empty($item['is_trap'])) {
            // 陷阱（v1 简化：仅写日志，不造成伤害，不获得道具）
            $display_name = $real_itm;
            $log .= "你伸手去拿<span class=\"yellow\">{$display_name}</span>——<br>";
            $log .= "<span class=\"red\">那是一个陷阱！</span><br>";
            // 删除道具实例
            $db->query("DELETE FROM {$tablepre}oblmapitem WHERE iid='$iid'");
            return;
        }
        // 正常近视道具：揭示真实名称
        $log .= "你拿起了看似普通的东西——原来是<span class=\"yellow\">{$real_itm}</span>！<br>";
    }

    // 5. 写入玩家背包（寻找空槽位 itm1~itm6）
    $slot = -1;
    for ($i = 1; $i <= 6; $i++) {
        $key = 'itm' . $i;
        if (empty($pdata[$key]) || $pdata[$key] === '') {
            $slot = $i;
            break;
        }
    }

    if ($slot === -1) {
        $log .= '背包已满，无法拾取。<br>';
        return;
    }

    // 写入背包槽位（item_id 保存到 itmpara JSON 数组中，键 obl_item_id）
    $pdata['itm' . $slot]  = $item['itm'];
    $pdata['itmk' . $slot] = $item['itmk'];
    $pdata['itme' . $slot] = $item['itme'];
    $pdata['itms' . $slot] = $item['itms'];
    $pdata['itmsk' . $slot] = $item['itmsk'];
    // 将 item_id 注入 itmpara JSON 数组，丢弃时可还原
    $para = json_decode($item['itmpara'], true) ?: [];
    $para['obl_item_id'] = $item['item_id'];
    $pdata['itmpara' . $slot] = json_encode($para, JSON_UNESCAPED_UNICODE);

    // 6. 删除地图道具实例
    $db->query("DELETE FROM {$tablepre}oblmapitem WHERE iid='$iid'");

    // 7. 日志
    if (!$was_nearsighted) {
        $log .= "你拾取了<span class=\"yellow\">{$real_itm}</span>。<br>";
    }
}
```

### 4.8 obl_discard_item() — 丢弃道具

```php
/**
 * 从背包丢弃道具到当前地图格
 * 道具从背包槽位删除，写入 bra_oblmapitem（iaid=0, discovered=1）
 * 其他玩家/后续可拾取
 *
 * @param int   $slot   背包槽位号（1~6）
 * @param array &$pdata 玩家数据
 */
function obl_discard_item($slot, &$pdata) {
    global $db, $tablepre, $log;

    $slot = (int)$slot;
    if ($slot < 1 || $slot > 6) {
        $log .= '无效的背包槽位。<br>';
        return;
    }

    $key = 'itm' . $slot;
    if (empty($pdata[$key]) || $pdata[$key] === '') {
        $log .= '该槽位没有道具。<br>';
        return;
    }

    // 读取道具数据
    $itm     = $pdata['itm' . $slot];
    $itmk    = $pdata['itmk' . $slot];
    $itme    = (int)$pdata['itme' . $slot];
    $itms    = $pdata['itms' . $slot];
    $itmsk   = $pdata['itmsk' . $slot];
    $itmpara_raw = $pdata['itmpara' . $slot];

    // 从 itmpara JSON 中提取 item_id（键 obl_item_id），并还原原始 itmpara
    $para = json_decode($itmpara_raw, true) ?: [];
    $item_id = isset($para['obl_item_id']) ? $para['obl_item_id'] : '';
    unset($para['obl_item_id']);
    $itmpara = empty($para) ? '' : json_encode($para, JSON_UNESCAPED_UNICODE);

    $cur_pgroup = (int)$pdata['pgroup'];
    $cur_pls = (int)$pdata['pls'];

    // 写入地图道具表（iaid=0 散落道具，discovered=1 立即可见，item_id 还原）
    $itm_e     = $db->escape_string($itm);
    $itmk_e    = $db->escape_string($itmk);
    $itms_e    = $db->escape_string($itms);
    $itmsk_e   = $db->escape_string($itmsk);
    $itmpara_e = $db->escape_string($itmpara);
    $item_id_e = $db->escape_string($item_id);

    $db->query("INSERT INTO {$tablepre}oblmapitem
                (pgroup, pls, iaid, item_id, itm, itmk, itme, itms, itmsk, itmpara, discovered, fake_item_id, is_trap)
                VALUES ('$cur_pgroup', '$cur_pls', 0, '$item_id_e', '$itm_e', '$itmk_e', '$itme', '$itms_e', '$itmsk_e', '$itmpara_e', 1, '', 0)");

    // 清空背包槽位
    $pdata['itm' . $slot]     = '';
    $pdata['itmk' . $slot]    = '';
    $pdata['itme' . $slot]    = 0;
    $pdata['itms' . $slot]    = '';
    $pdata['itmsk' . $slot]   = '';
    $pdata['itmpara' . $slot] = '';

    $log .= "你丢弃了<span class=\"yellow\">{$itm}</span>。<br>";
}
```

### 4.9 obl_check_move_sp() — 移动体力检查

```php
/**
 * 检查玩家是否满足移动消耗的体力
 * 独立函数，从 obl_move() 中抽取
 *
 * @param array &$pdata   玩家数据
 * @param int   $distance 移动距离（格数）
 * @return bool true=体力充足，false=体力不足
 */
function obl_check_move_sp(&$pdata, $distance = 1) {
    global $log;

    $obl_config = include GAME_ROOT . './oblivions/gamedata/obl_config.php';
    $base_cost = (int)($obl_config['move_sp_cost'] ?? 0);
    $cost = $distance * $base_cost;

    if ($pdata['sp'] < $cost) {
        $log .= '体力不足，无法移动。<br>';
        return false;
    }

    // 扣除体力
    $pdata['sp'] -= $cost;
    return true;
}
```

```php
function handle_tile_actions() {
    global $pdata, $db, $tablepre;

    if (!oblivions_is_active()) {
        api_error('非 Oblivions 模式', 'NOT_OBLIVIONS');
    }

    $pgroup = (int)$pdata['pgroup'];

    // 1. 读取当前格 POI（仅迷雾清除后的）
    $poi_result = $db->query("SELECT p.* FROM {$tablepre}oblmappoi p
                               INNER JOIN {$tablepre}oblmapstates s
                               ON p.pgroup=s.pgroup AND p.pls=s.pls
                               WHERE p.pgroup='$pgroup' AND p.pls='$pls' AND s.fog=1");
    $pois = [];
    $poi_iaids = [];

    $poi_table = include GAME_ROOT . './oblivions/gamedata/poi_table.php';

    while ($poi = $db->fetch_array($poi_result)) {
        $poi_id = $poi['poi_id'];
        $tpl = $poi_table[$poi_id] ?? null;
        if (!$tpl) continue;

        $poi_iaids[] = (int)$poi['iaid'];
        $poi_data = [
            'iaid'          => (int)$poi['iaid'],
            'poi_id'        => $poi_id,
            'name'          => $tpl['name'],
            'desc'          => $tpl['desc'],
            'searchable'    => !empty($tpl['searchable']),
            'repeatable'    => !empty($tpl['repeatable']),
            'searched'      => !empty($poi['searched']),
            'search_count'  => (int)$poi['search_count'],
            'items'         => [],
        ];

        // 可重复搜索属性
        if (!empty($tpl['repeatable'])) {
            $poi_data['repeat_limit'] = (int)($tpl['repeat_limit'] ?? 0);
            $poi_data['repeat_cooldown'] = (int)($tpl['repeat_cooldown'] ?? 0);
        }

        // 机制属性
        if (!empty($tpl['mechanic'])) {
            $poi_data['mechanic'] = $tpl['mechanic'];
            if (isset($tpl['mechanic_value'])) {
                $poi_data['mechanic_value'] = $tpl['mechanic_value'];
            }
            if (isset($tpl['mechanic_params'])) {
                $poi_data['mechanic_params'] = $tpl['mechanic_params'];
            }
        }

        $pois[] = $poi_data;
    }

    // 2. 读取当前格已发现的道具（按 iaid 分组）
    $item_result = $db->query("SELECT * FROM {$tablepre}oblmapitem
                                WHERE pgroup='$pgroup' AND pls='$pls' AND discovered>0");

    $items_by_iaid = [];  // iaid => [item, ...]
    $ground_items = [];   // iaid=0 的道具

    while ($item = $db->fetch_array($item_result)) {
        $iaid = (int)$item['iaid'];
        $item_data = [
            'iid'       => (int)$item['iid'],
            'item_id'   => $item['item_id'],
            'itm'       => $item['itm'],
            'itmk'      => $item['itmk'],
            'itme'      => (int)$item['itme'],
            'itms'      => $item['itms'],
            'itmsk'     => $item['itmsk'],
            'itmpara'   => $item['itmpara'],
            'discovered'=> (int)$item['discovered'],
        ];

        // 近视道具附加信息
        if ((int)$item['discovered'] === 2) {
            $fake_id = $item['fake_item_id'];
            if (!empty($fake_id)) {
                $item_table = include GAME_ROOT . './oblivions/gamedata/item_table.php';
                $display_name = isset($item_table[$fake_id])
                    ? $item_table[$fake_id]['itm'] . '（？）'
                    : $item['itm'] . '（？）';
            } else {
                $display_name = $item['itm'] . '（？）';
            }
            $item_data['display_name'] = $display_name;
            $item_data['fake_item_id'] = $fake_id;
            $item_data['is_trap'] = !empty($item['is_trap']) ? 1 : 0;
        }

        if ($iaid === 0) {
            $ground_items[] = $item_data;
        } else {
            if (!isset($items_by_iaid[$iaid])) {
                $items_by_iaid[$iaid] = [];
            }
            $items_by_iaid[$iaid][] = $item_data;
        }
    }

    // 3. 将道具分配到对应 POI
    foreach ($pois as &$poi) {
        if (isset($items_by_iaid[$poi['iaid']])) {
            $poi['items'] = $items_by_iaid[$poi['iaid']];
        }
    }
    unset($poi);

    api_response('success', [
        'pois'         => $pois,
        'ground_items' => $ground_items,
    ]);
}
```
