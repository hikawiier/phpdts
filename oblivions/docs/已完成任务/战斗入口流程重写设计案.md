# 战斗入口流程重写设计案

> 目标：重写 `obl_battle_start` → `cmd_handle_obl_battle_start` → `battle_queue_create` 流程，厘清生命周期，修复 NPC 不接先攻轮的 BUG，并引入基于属性的先攻率计算。

---

## 一、问题背景

### 1.1 当前 BUG 现象

玩家突袭 NPC 后，NPC 没有接过先攻攻击玩家，导致 `obl_tick_pending_npc` 无法解锁，玩家被永久锁定。

### 1.2 根因分析

1. **ambush_flag 生命周期管理混乱**：
   - 设置在 `cmd_handle_obl_battle_start`
   - 使用在 `battle_queue_create`（先攻顺位判定）
   - **从未清除** → 残留在 `oblpara` 中 → 后续逻辑可能误判

2. **先攻判定逻辑硬编码**：
   - `battle_queue_create` 中突袭者强制 `myorder=1`，其他人 `mt_rand(2, 100)`
   - 没有基于属性的先攻率计算
   - 先攻顺位随机性过大，无法体现角色属性差异

3. **指令格式不统一**：
   - `obl_battle_start` 传 `enemy_pid` + `actions`
   - `obl_battle_action` 传 `action_id` + `target_pid` + `actions`（冗余）
   - 前端实际已打包 `actions` 数组，后端接收格式应统一

---

## 二、设计目标

1. **厘清生命周期**：明确 ambush_flag 的"设置→使用→清除"一次性生命周期
2. **统一指令格式**：`obl_battle_start` 和 `obl_battle_action` 都只传 `actions`
3. **引入先攻率计算**：基于属性的先攻顺位判定，ambush_flag 作为顺位 1 的强制标记
4. **保留合法性校验**：前端拦截 + 后端 battle_verify 双重校验
5. **最小化前端改动**：前端 actions 数组结构不变，后端忽略 `id` 字段

---

## 三、核心设计

### 3.1 指令格式统一

#### 3.1.1 `obl_battle_start`（突袭入口）

**前端提交参数**：
```
command=obl_battle_start
actions=[{"id":1,"act_id":"unarmed_strike","target":20},...]
```

**后端接收**：
- `actions`：JSON 数组，每项含 `act_id` + `target`（`id` 字段忽略）
- 突袭目标：从 `actions[0]['target']` 推导（突袭必然有第一个攻击目标）

**`cmd_handle_obl_battle_start` 新签名**：
```php
function cmd_handle_obl_battle_start(&$pdata, $actions = null) {
    // 1. 解析 actions，提取突袭目标
    // 2. 校验突袭目标合法性（存在、未死亡、已发现、同区域、射程内）
    // 3. 设置 ambush_flag（一次性，用于先攻判定）
    // 4. battle_state_init($pdata) → 玩家进入战斗状态
    // 5. 调用 battle_main($pdata, $atk_act, $obl_battle_log)
}
```

#### 3.1.2 `obl_battle_action`（玩家先攻轮）

**前端提交参数**：
```
command=obl_battle_action
actions=[{"id":1,"act_id":"unarmed_strike","target":20},...]
```

**后端接收**：
- `actions`：JSON 数组，每项含 `act_id` + `target`
- 移除冗余的 `action_id` + `target_pid` 参数

**`cmd_handle_obl_battle_action` 新签名**：
```php
function cmd_handle_obl_battle_action(&$pdata, $actions = null) {
    // 1. 解析 actions
    // 2. 调用 battle_main($pdata, $atk_act, $obl_battle_log)
}
```

#### 3.1.3 路由层改造

`router.php` 中：
- `obl_battle_start`：移除 `enemy_pid` 参数提取，只提取 `actions`
- `obl_battle_action`：移除 `action_id` + `target_pid` 参数提取，只提取 `actions`

### 3.2 ambush_flag 生命周期

```
[设置] cmd_handle_obl_battle_start
    ↓
[使用] battle_queue_create（先攻判定：强制顺位 1）
    ↓
[清除] battle_queue_create（使用后立即 unset，一次性）
```

**关键约束**：
- ambush_flag 只在 `cmd_handle_obl_battle_start` 中设置
- ambush_flag 只在 `battle_queue_create` 中使用一次
- 使用后立即 `unset($actor_data['oblpara']['ambush_flag'])`
- `obl_save_player` 时不会残留 ambush_flag

### 3.3 先攻率计算

#### 3.3.1 先攻属性获取函数

采用与 `obl_get_range` 一致的模式，封装先攻属性获取：

```php
/**
 * 获取对象的先攻属性
 *
 * 阶段一：读 oblpara['initiative']，未配置则返回 50。
 * 未来可扩展：+ 装备补正 + 技能补正。
 *
 * @param array &$actor_data 对象数据
 * @return int 先攻属性
 */
function obl_get_initiative(&$actor_data) {
    $basic_initiative = isset($actor_data['oblpara']['initiative'])
        ? (int)$actor_data['oblpara']['initiative'] : 50;
    return $basic_initiative;
}
```

- **玩家默认值**：50（未配置 oblpara['initiative'] 时）
- **NPC 默认值**：由 `enemies_config.php` 配置（写入 oblpara['initiative']，未配置则 50）
- **前端不直接消费**：前端通过 battlelog 的 `initiative.roll` 事件获取投掷结果

#### 3.3.2 投掷公式

```php
$roll = mt_rand(1, obl_get_initiative($combatant_data));  // 1~先攻属性，值越大越先攻
```

#### 3.3.3 排序规则（三级 tiebreak）

1. **投掷值降序**：`$roll` 越大越先攻
2. **先攻属性降序**：投掷值相同时，`$initiative` 越大越先攻
3. **玩家优先**：再相同时，`type=0`（玩家）优先

#### 3.3.4 ambush_flag 处理

- ambush_flag=true 的参战者：强制 `myorder=1`
- 其他参战者：正常投掷，`myorder` 从 2 开始递增
- **使用后立即清除 ambush_flag**

#### 3.3.5 先攻计算函数

```php
/**
 * 计算先攻顺位
 *
 * @param array &$actor_data 突袭者数据（含 ambush_flag）
 * @param array $combatants  参战者 PID 数组
 * @return array 排序后的先攻顺位数组 [['pid' => int, 'myorder' => int, 'roll' => int, 'initiative' => int, 'is_ambush' => bool], ...]
 */
function battle_calc_initiative(&$actor_data, $combatants) {
    $rolls = array();
    $ambush_pid = !empty($actor_data['oblpara']['ambush_flag']) ? (int)$actor_data['pid'] : 0;

    foreach ($combatants as $pid) {
        if ($pid == $ambush_pid) {
            // 突袭者强制顺位 1，不参与投掷
            $rolls[] = array(
                'pid' => (int)$pid,
                'roll' => 0,
                'initiative' => 0,
                'type' => (int)$actor_data['type'],
                'is_ambush' => true,
            );
            continue;
        }

        // 获取参战者数据
        if ($pid == $actor_data['pid']) {
            $combatant_data = &$actor_data;
        } else {
            $combatant_data = obl_fetch_playerdata_by_pid($pid);
            if (!$combatant_data) continue;
        }

        $initiative = obl_get_initiative($combatant_data);
        $roll = mt_rand(1, $initiative);
        $type = (int)$combatant_data['type'];

        $rolls[] = array(
            'pid' => (int)$pid,
            'roll' => $roll,
            'initiative' => $initiative,
            'type' => $type,
            'is_ambush' => false,
        );
    }

    // 排序：突袭者优先 → 投掷值降序 → 先攻属性降序 → 玩家优先
    usort($rolls, function($a, $b) {
        // 突袭者强制第一
        if ($a['is_ambush'] && !$b['is_ambush']) return -1;
        if (!$a['is_ambush'] && $b['is_ambush']) return 1;

        // 投掷值降序
        if ($a['roll'] !== $b['roll']) return $b['roll'] - $a['roll'];

        // 先攻属性降序
        if ($a['initiative'] !== $b['initiative']) return $b['initiative'] - $a['initiative'];

        // 玩家优先（type=0）
        if ($a['type'] == 0 && $b['type'] != 0) return -1;
        if ($a['type'] != 0 && $b['type'] == 0) return 1;

        return 0;
    });

    // 分配 myorder（从 1 开始递增）
    $result = array();
    $myorder = 1;
    foreach ($rolls as $r) {
        $r['myorder'] = $myorder++;
        $result[] = $r;
    }

    return $result;
}
```

#### 3.3.6 先攻计算结果加入 battlelog

在 `battle_queue_create` 中，先攻计算完成后 emit debug 日志。

**关键**：`is_ambush` 字段体现强制顺位信息，前端可通过 battlelog 获取完整的先攻对抗过程：

```php
if ($obl_battle_log) {
    $obl_battle_log->emit([
        'actor_pid'   => (int)$actor_data['pid'],
        'actor_type'  => (int)$actor_data['type'],
        'target_pid'  => 0,
        'target_type' => -1,
        'action_id'   => 'initiative.roll',
        'extra'       => [
            'qid' => $qid,
            'rolls' => $initiative_result,  // 完整投掷结果（含 is_ambush 标记）
            'ambush_pid' => $ambush_pid,    // 强制顺位者 PID（0=无突袭）
        ],
    ]);
}
```

**battlelog 中的 `rolls` 数组结构**（前端可读取）：
```json
[
  {"pid": 5, "roll": 0, "initiative": 0, "type": 0, "is_ambush": true, "myorder": 1},
  {"pid": 101, "roll": 35, "initiative": 40, "type": 1, "is_ambush": false, "myorder": 2}
]
```
- `is_ambush=true` 表示该参战者被强制顺位 1（未参与投掷，roll/initiative 为 0）
- `is_ambush=false` 表示该参战者正常投掷（roll/initiative 为实际值）

### 3.4 `battle_queue_create` 重写

```php
function battle_queue_create(&$actor_data, &$combatants, &$obl_battle_log) {
    global $db, $tablepre;

    // 1. 生成新的 qid
    $result = $db->query("SELECT MAX(qid) AS max_qid FROM {$tablepre}oblqueue");
    $row = $db->fetch_array($result);
    $qid = $row && $row['max_qid'] ? (int)$row['max_qid'] + 1 : 1;

    // 2. 计算先攻顺位
    $initiative_result = battle_calc_initiative($actor_data, $combatants);

    // 3. emit 先攻计算 debug 日志
    if ($obl_battle_log) {
        $obl_battle_log->emit([
            'actor_pid'   => (int)$actor_data['pid'],
            'actor_type'  => (int)$actor_data['type'],
            'target_pid'  => 0,
            'target_type' => -1,
            'action_id'   => 'initiative.roll',
            'extra'       => [
                'qid' => $qid,
                'rolls' => $initiative_result,
            ],
        ]);
    }

    // 4. 插入队列记录
    foreach ($initiative_result as $r) {
        $pid = $r['pid'];

        // 获取 type
        if ($pid == $actor_data['pid']) {
            $type = $actor_data['type'];
        } else {
            $combatant_data = obl_fetch_playerdata_by_pid($pid);
            if (!$combatant_data) continue;
            $type = $combatant_data['type'];
        }

        // 清理旧队列记录
        $db->query("DELETE FROM {$tablepre}oblqueue WHERE pid = " . (int)$pid);

        // 插入新记录
        $db->query("INSERT INTO {$tablepre}oblqueue (pid, qid, type, qorder, myorder, done) VALUES ("
            . (int)$pid . ", " . (int)$qid . ", " . (int)$type . ", 0, " . (int)$r['myorder'] . ", 0)");

        // 更新 bid
        if ($pid == $actor_data['pid']) {
            $actor_data['bid'] = $qid;
        } else {
            $db->query("UPDATE {$tablepre}oblplayers SET bid = " . (int)$qid . " WHERE pid = " . (int)$pid);
        }
    }

    // 5. 清除 ambush_flag（一次性，使用完毕）
    if (isset($actor_data['oblpara']['ambush_flag'])) {
        unset($actor_data['oblpara']['ambush_flag']);
    }

    // 6. 保存动作发起者（bid 已修改，ambush_flag 已清除）
    obl_save_player($actor_data);

    // 7. emit 队列创建日志
    if ($obl_battle_log) {
        $obl_battle_log->emit([
            'actor_pid'   => (int)$actor_data['pid'],
            'actor_type'  => (int)$actor_data['type'],
            'target_pid'  => 0,
            'target_type' => -1,
            'action_id'   => 'queue_create',
            'extra'       => ['qid' => $qid, 'combatants' => $combatants],
        ]);
    }
}
```

### 3.5 `cmd_handle_obl_battle_start` 重写

```php
function cmd_handle_obl_battle_start(&$pdata, $actions = null) {
    if (!oblivions_is_active()) return;
    include_once GAME_ROOT . './oblivions/include/game/battle/battle.main.php';
    include_once GAME_ROOT . './oblivions/include/game/move.func.php';

    global $obl_log, $obl_battle_log;

    // 1. 解析 actions，提取突袭目标
    $atk_act = array();
    $ambush_target_pid = 0;
    if (is_array($actions)) {
        foreach ($actions as $act) {
            $act_id = isset($act['act_id']) ? $act['act_id'] : '';
            $target = isset($act['target']) ? (int)$act['target'] : 0;
            if (empty($act_id) || $target <= 0) continue;

            $atk_act[] = array('act_id' => $act_id, 'target' => $target);

            // 第一个有效动作的 target 作为突袭目标
            if ($ambush_target_pid === 0) {
                $ambush_target_pid = $target;
            }
        }
    }

    if (empty($atk_act) || $ambush_target_pid <= 0) return;

    // 2. 校验突袭目标合法性
    $enemy = obl_fetch_playerdata_by_pid($ambush_target_pid);
    if (!$enemy) return;
    obl_format_playerdata($enemy);

    if ((int)$enemy['state'] !== 0) return;          // 未死亡
    if (empty($enemy['discovered'])) return;          // 已发现
    if ((int)$enemy['pgroup'] !== (int)$pdata['pgroup']) return;  // 同区域
    $distance = obl_get_distance($pdata['pgroup'], $pdata['pls'], $enemy['pls']);
    if ($distance < 0 || $distance > obl_get_range($pdata)) return;  // 射程内

    // 3. 初始化 battle_log
    if (!$obl_battle_log) {
        include_once GAME_ROOT . './oblivions/include/game/battle_log.func.php';
        $obl_battle_log = new BattleLogCollector();
    }

    // 4. 设置 ambush_flag（一次性，battle_queue_create 中清除）
    $pdata['oblpara']['ambush_flag'] = true;

    // 5. 玩家进入战斗状态
    battle_state_init($pdata);

    // 6. 调用 battle_main（内部会完成后补票创建先攻队列 + 先攻判定）
    battle_main($pdata, $atk_act, $obl_battle_log);
}
```
