# Oblivions 初始化集成设计

> 版本：1.0 | 2026-06-14
> 描述 Oblivions 模式在 rs_game() 中的初始化集成方案

---

## 一、现有机制分析

### 1.1 rs_game() 位掩码

```php
// include/gamectl/system.func.php
function rs_game($mode = 0) {
    if ($mode & 1)  rs_reset_social();    // 重置社交数据 + reset.sql 建表
    if ($mode & 2)  rs_init_areas();      // 初始化禁区/天气
    if ($mode & 4)  rs_init_players();    // 重建玩家表
    if ($mode & 8)  rs_init_npcs();       // 初始化 NPC
    if ($mode & 16) rs_init_mapitems();   // 初始化地图道具
    if ($mode & 32) rs_init_shops();      // 初始化商店
}
```

调用点：`gamestate_try_prepare()` 中 `rs_game(1+2+4+8+16+32)` = `rs_game(63)`

### 1.2 reset.sql 建表模式

`rs_reset_social()` 通过 `reset.sql` 批量建表：

```php
$sql = file_get_contents("{$sqldir}reset.sql");
$sql = str_replace(' bra_', ' '.$tablepre, $sql);  // 替换表前缀
$db->queries($sql);
```

所有 `bra_` 前缀的表在 `reset.sql` 中 DROP + CREATE，游戏重置时自动清理。

### 1.3 Oblivions 现有分支

- `rs_init_areas()`：`oblivions_is_active()` 时跳过禁区初始化
- `gamestate_try_add_area()`：Oblivions 跳过禁区推进
- `gamestate_try_stop_valid()`：Oblivions 跳过停止激活
- `gamestate_try_combo()`：Oblivions 跳过连斗
- `gamestate_try_gameover()`：Oblivions 不自动结束

## 二、集成方案

### 2.1 新增位掩码

```
64 (RS_FLAG_OBLIVIONS) = 初始化 Oblivions 地图数据
```

仅当 `oblivions_is_active()` 时执行，非 Oblivions 模式完全无影响。

### 2.2 rs_game() 修改

```php
function rs_game($mode = 0) {
    $mode = (int) $mode;
    if ($mode & 1)  rs_reset_social();
    if ($mode & 2)  rs_init_areas();
    if ($mode & 4)  rs_init_players();
    if ($mode & 8)  { if (rs_init_npcs() === false) return; }
    if ($mode & 16) rs_init_mapitems();
    if ($mode & 32) rs_init_shops();
    if ($mode & 64) rs_init_oblivions();    // 新增
}
```

### 2.3 调用点修改

`gamestate_try_prepare()` 中：

```php
// 旧
rs_game(1 + 2 + 4 + 8 + 16 + 32);

// 新：Oblivions 模式追加 64
rs_game(63 + (oblivions_is_active() ? 64 : 0));
```

## 三、rs_init_oblivions() 设计

### 3.1 函数签名

```php
/**
 * 初始化 Oblivions 地图数据
 *
 * 流程：建表 → 载入配置 → 生成 POI → 生成野生道具 → 初始化迷雾
 * 仅在 oblivions_is_active() 时由 rs_game(64) 调用
 */
function rs_init_oblivions() {
    global $db, $tablepre;

    // 1. 建表
    rs_init_oblivions_tables();

    // 2. 载入配置
    $poi_table   = include GAME_ROOT . 'oblivions/gamedata/poi_table.php';
    $poi_loot    = include GAME_ROOT . 'oblivions/gamedata/poi_loot.php';
    $poi_pool    = include GAME_ROOT . 'oblivions/gamedata/poi_pool.php';
    $item_table  = include GAME_ROOT . 'oblivions/gamedata/item_table.php';
    $scatter_pool = include GAME_ROOT . 'oblivions/gamedata/scatter_pool.php';

    // 3. 读取地图数据
    $map_data = include GAME_ROOT . 'oblivions/gamedata/map.php';

    // 4. 遍历所有区域，生成 POI 和野生道具
    foreach ($map_data['regions'] as $pgroup => $region) {
        // 按需加载该区域的地图格数据
        $tiles = include GAME_ROOT . "oblivions/gamedata/tiles/region_{$pgroup}.php";
        obl_generate_region_pois($pgroup, $tiles, $poi_pool, $poi_table);
        obl_generate_wild_items($pgroup, $tiles, $scatter_pool, $item_table);
    }

    // 5. 初始化迷雾（所有格 fog=0，玩家出生时点亮）
    rs_init_oblivions_fog($map_data);
}
```

### 3.2 建表方式

**方案：Oblivions 独立管理自己的 3 张表**

不修改 `reset.sql`，Oblivions 的 3 张表完全由 `rs_init_oblivions_tables()` 自行 DROP + CREATE：

```php
function rs_init_oblivions_tables() {
    global $db, $tablepre;
    $sqldir = GAME_ROOT . 'oblivions/sql/';

    $tables = ['oblmappoi.sql', 'oblmapitem.sql', 'oblmapstates.sql'];
    foreach ($tables as $file) {
        $sql = file_get_contents($sqldir . $file);
        $sql = str_replace("\r", "\n", str_replace(' bra_', ' '.$tablepre, $sql));
        $db->queries($sql);
    }
}
```

每个 SQL 文件内含 DROP TABLE IF EXISTS + CREATE TABLE，与 `reset.sql` 模式一致但完全独立。

**理由**：
- Oblivions 是可选模块，不应污染核心 `reset.sql`
- 非 Oblivions 局不会执行 `rs_init_oblivions_tables()`，3 张表不会被创建
- 上一局 Oblivions 残留表在下一局 Oblivions 初始化时由 DROP IF EXISTS 自动清理
- 非 Oblivions 局切换后，残留表不会被清理（可接受，或由 GM 手动清理）

### 3.3 配置文件载入顺序

```
1. map.php          → 地图结构（区域/网格/邻接表）
2. poi_table.php    → POI 模板属性
3. poi_loot.php     → POI 掉落表
4. poi_pool.php     → POI 刷新配置
5. item_table.php   → 道具模板属性
6. scatter_pool.php → 野生散落道具池
```

载入发生在 `rs_init_oblivions()` 内部，不在全局 scope，避免非 Oblivions 模式加载无用配置。

### 3.4 迷雾初始化

```php
function rs_init_oblivions_fog($map_data) {
    global $db, $tablepre;

    // 所有地图格插入 bra_oblmapstates，fog=0
    foreach ($map_data['regions'] as $pgroup => $region) {
        $tiles = include GAME_ROOT . "oblivions/gamedata/tiles/region_{$pgroup}.php";
        $values = [];
        $pgroup_i = (int)$pgroup;
        foreach ($tiles as $pls => $tile) {
            $pls = (int)$pls;
            $values[] = "($pgroup_i, $pls, 0, 0, '')";
        }
        if (!empty($values)) {
            $qry = "INSERT INTO {$tablepre}oblmapstates (pgroup, pls, fog, damaged, flags)
                    VALUES " . implode(',', $values);
            $db->query($qry);
        }
    }
}
```

**玩家出生点迷雾**：不在初始化时点亮，而是在玩家进入游戏（valid.php/command.php）时调用 `obl_update_vision()` 点亮出生格及视野范围。

理由：初始化时玩家尚未出生，出生位置取决于 valid 流程，不在 rs_game 阶段。

## 四、生成函数设计

### 4.1 obl_generate_region_pois()

```php
/**
 * 为指定区域生成 POI 实例
 * @param int   $pgroup    区域 ID
 * @param array $region    区域数据（来自 map.php）
 * @param array $poi_pool  POI 刷新配置（来自 poi_pool.php）
 * @param array $poi_table POI 模板属性（来自 poi_table.php）
 */
function obl_generate_region_pois($pgroup, $region, $poi_pool, $poi_table) {
    global $db, $tablepre;

    // 1. 获取该区域的潮汐类型
    $tide = $region['tide'] ?? 'shallow';

    // 2. 获取该潮汐区的 POI 列表
    if (!isset($poi_pool[$tide])) return;
    $pool = $poi_pool[$tide];

    // 3. 获取该区域所有可放置的地图格
    $grids = array_keys($region['grids']);
    $occupied = array();  // 已放置 POI 的格

    // 4. 逐个 POI 配置生成
    foreach ($pool as $cfg) {
        $poi_id = $db->escape_string($cfg['poi_id']);
        $count  = (int)$cfg['per_region'];
        $pgroup = (int)$pgroup;

        // 排除已占格
        $available = array_diff($grids, $occupied);
        if (count($available) < $count) {
            $count = count($available);
        }
        if ($count <= 0) continue;

        // 随机选择地图格
        $selected = array_rand(array_flip($available), $count);
        if (!is_array($selected)) $selected = [$selected];

        // 批量插入
        $values = [];
        foreach ($selected as $pls) {
            $pls = (int)$pls;
            $values[] = "($pgroup, $pls, '$poi_id', 0, 0, 0)";
            $occupied[] = $pls;
        }
        $qry = "INSERT INTO {$tablepre}oblmappoi
                (pgroup, pls, poi_id, searched, search_count, last_search_turn)
                VALUES " . implode(',', $values);
        $db->query($qry);
    }
}
```

### 4.2 obl_generate_wild_items()

```php
/**
 * 为指定区域生成野生散落道具
 * @param int   $pgroup      区域 ID
 * @param array $region      区域数据
 * @param array $scatter_pool 野生道具池
 * @param array $item_table  道具模板
 */
function obl_generate_wild_items($pgroup, $region, $scatter_pool, $item_table) {
    global $db, $tablepre;

    $tide = $region['tide'] ?? 'shallow';
    if (!isset($scatter_pool[$tide])) return;

    $grids = array_keys($region['grids']);
    $values = [];

    foreach ($scatter_pool[$tide] as $cfg) {
        $item_id = $cfg['item_id'];
        $count   = is_array($cfg['count']) ? rand($cfg['count'][0], $cfg['count'][1]) : $cfg['count'];
        $rate    = $cfg['rate'];

        // 每个格独立判定
        foreach ($grids as $pls) {
            if (mt_rand() / mt_getrandmax() > $rate) continue;

            $template = $item_table[$item_id];
            $itm    = $db->escape_string($template['itm']);
            $itmk   = $db->escape_string($template['itmk']);
            $itme   = $template['itme'];
            $itms   = $template['itms'];
            $itmsk  = $db->escape_string($template['itmsk']);
            $itmpara = $db->escape_string($template['itmpara']);

            $values[] = "('$pgroup', '$pls', 0, '$item_id', '$itm', '$itmk', '$itme', '$itms', '$itmsk', '$itmpara', 0, '', 0)";
        }
    }

    // 批量插入
    if (!empty($values)) {
        // 分批插入，每批 500 条
        $batches = array_chunk($values, 500);
        foreach ($batches as $batch) {
            $qry = "INSERT INTO {$tablepre}oblmapitem
                    (pgroup, pls, iaid, item_id, itm, itmk, itme, itms, itmsk, itmpara, discovered, fake_item_id, is_trap)
                    VALUES " . implode(',', $batch);
            $db->query($qry);
        }
    }
}
```

## 五、执行时序

```
gamestate_try_prepare()
  └── rs_game(63 + 64)    // Oblivions 模式
      ├── rs_reset_social()     → reset.sql 建表（不涉及 Oblivions 表）
      ├── rs_init_areas()       → Oblivions: 跳过禁区，仅初始化天气
      ├── rs_init_players()     → 重建玩家表
      ├── rs_init_npcs()        → 初始化 NPC
      ├── rs_init_mapitems()    → 初始化旧版地图道具
      ├── rs_init_shops()       → 初始化商店
      └── rs_init_oblivions()   → [新增]
          ├── rs_init_oblivions_tables()   → 建表（oblmappoi/oblmapitem/oblmapstates）
          ├── 载入配置文件
          ├── 遍历区域生成 POI
          ├── 遍历区域生成野生道具
          └── 初始化迷雾（所有格 fog=0）

玩家进入游戏（valid.php）
  └── obl_update_vision()  → 点亮出生格及视野范围迷雾
```

## 七、注意事项

1. **非 Oblivions 模式无影响**：`rs_game(64)` 仅在 `oblivions_is_active()` 时传入，现有流程 `rs_game(63)` 不触发
2. **SQL 安全**：所有字符串值经 `$db->escape_string()` 转义，所有数值经 `(int)` 强转，数值在 SQL 中不加引号。纵然数据来自开发者配置文件，仍遵循纵深防御原则
3. **配置文件延迟加载**：仅在 `rs_init_oblivions()` 内 include，非 Oblivions 模式零开销
4. **批量插入**：野生道具可能较多，分批 500 条插入避免 SQL 过长
5. **近视道具**：野生道具初始化时 discovered=0，近视判定在探索时由 `obl_update_vision()` 设置
6. **地图数据依赖**：`obl_generate_region_pois()` 和 `obl_generate_wild_items()` 依赖 `map.php` 的区域/网格结构，需确保 map.php 已就绪
