# 地图缩放/平移/自动居中 设计方案

> 版本：1.0 | 日期：2026-06-15

---

## 一、需求分析

### 1.1 当前问题

- 地图格尺寸固定（桌面 48-80px，移动端 32-48px），无法放大查看细节
- 移动端格子太小（33px），文字被截断为省略号，无法辨认地名
- 玩家位置可能在地图任意位置，视觉上不突出
- 地图区域大于可视区域时，无法滚动查看

### 1.2 目标

| 功能 | 桌面端 | 移动端 |
|------|--------|--------|
| 缩放 | 鼠标滚轮 | 双指缩放 |
| 平移 | 左键拖拽 | 单指拖拽 |
| 自动居中 | 移动/探索后自动居中到玩家格 | 同左 |
| 双击/双击缩放 | 双击格子放大到该格 | 双击格子放大 |

---

## 二、技术方案

### 2.1 核心思路：scroll-based 方案

**不使用 CSS transform**（会破坏点击坐标），而是通过调整格子尺寸实现缩放，通过 `scrollTo()` 实现平移和居中。

```
缩放 = 改变 cellSize → grid 总尺寸变化 → 容器 overflow:auto 自动出现滚动条
平移 = 容器 scrollTo(x, y)
居中 = 计算玩家格在 grid 中的偏移 → scrollTo 使其居中
```

**优势**：
- 点击事件天然正确（格子就是 DOM 元素，不需要坐标转换）
- 滚动条自动出现/消失
- 浏览器原生滚动惯性（移动端丝滑）
- 无需处理 transform-origin / 坐标映射

### 2.2 缩放状态

```javascript
// map.js 新增状态
let zoomLevel = 1;        // 缩放倍率，1 = 默认尺寸
const ZOOM_MIN = 0.5;     // 最小缩放（看全图）
const ZOOM_MAX = 2.5;     // 最大缩放（看单格细节）
const ZOOM_STEP = 0.15;   // 每次滚轮/双击的缩放步进
```

缩放时重新计算 cellSize：

```javascript
function getCellSize(cols) {
    const isMobile = window.innerWidth <= 900;
    const baseMin = isMobile ? 32 : 48;
    const baseMax = isMobile ? 48 : 80;
    const containerWidth = grid.parentElement.offsetWidth - 16;
    const baseSize = Math.max(baseMin, Math.min(baseMax, Math.floor(containerWidth / cols)));
    return Math.round(baseSize * zoomLevel);
}
```

### 2.3 自动居中

```javascript
function centerOnPlayer() {
    const grid = document.getElementById('mapGrid');
    const container = grid.parentElement;  // 滚动容器
    const playerCell = grid.querySelector('.map-cell.current');
    if (!playerCell || !container) return;

    const cellRect = playerCell.getBoundingClientRect();
    const containerRect = container.getBoundingClientRect();

    // 计算玩家格在 grid 中的偏移
    const gridRect = grid.getBoundingClientRect();
    const cellOffsetX = cellRect.left - gridRect.left + cellRect.width / 2;
    const cellOffsetY = cellRect.top - gridRect.top + cellRect.height / 2;

    // 滚动到使玩家格居中
    const scrollX = cellOffsetX - containerRect.width / 2;
    const scrollY = cellOffsetY - containerRect.height / 2;

    container.scrollTo({
        left: Math.max(0, scrollX),
        top: Math.max(0, scrollY),
        behavior: 'smooth'
    });
}
```

**触发时机**：
- `loadMap()` 渲染完成后
- `clickMove()` 移动成功后
- 缩放操作后（保持玩家格在中心）

### 2.4 滚轮缩放（桌面端）

```javascript
const mapContainer = document.getElementById('mapContainer'); // 需要加 id

mapContainer.addEventListener('wheel', function(e) {
    e.preventDefault();
    const delta = e.deltaY > 0 ? -ZOOM_STEP : ZOOM_STEP;
    const newZoom = Math.max(ZOOM_MIN, Math.min(ZOOM_MAX, zoomLevel + delta));

    if (newZoom !== zoomLevel) {
        zoomLevel = newZoom;
        renderMapGrid();       // 重新渲染（改变格子尺寸）
        centerOnPlayer();      // 缩放后保持居中
    }
}, { passive: false });
```

### 2.5 拖拽平移

```javascript
let isDragging = false;
let dragStartX = 0, dragStartY = 0;
let scrollStartX = 0, scrollStartY = 0;

mapContainer.addEventListener('mousedown', function(e) {
    // 只在地图容器空白处拖拽，不阻断格子点击
    if (e.target === mapContainer || e.target.id === 'mapGrid') {
        isDragging = true;
        dragStartX = e.clientX;
        dragStartY = e.clientY;
        scrollStartX = mapContainer.scrollLeft;
        scrollStartY = mapContainer.scrollTop;
        mapContainer.style.cursor = 'grabbing';
    }
});

document.addEventListener('mousemove', function(e) {
    if (!isDragging) return;
    const dx = e.clientX - dragStartX;
    const dy = e.clientY - dragStartY;
    mapContainer.scrollLeft = scrollStartX - dx;
    mapContainer.scrollTop = scrollStartY - dy;
});

document.addEventListener('mouseup', function() {
    if (isDragging) {
        isDragging = false;
        mapContainer.style.cursor = '';
    }
});
```

### 2.6 触摸缩放/平移（移动端）

```javascript
let touchStartDist = 0;
let touchStartZoom = 1;
let touchStartX = 0, touchStartY = 0;
let touchScrollX = 0, touchScrollY = 0;
let isTouchZooming = false;

mapContainer.addEventListener('touchstart', function(e) {
    if (e.touches.length === 2) {
        // 双指 → 缩放
        isTouchZooming = true;
        touchStartDist = getTouchDistance(e.touches);
        touchStartZoom = zoomLevel;
    } else if (e.touches.length === 1) {
        // 单指 → 平移（记录起始位置，让浏览器原生滚动处理）
        touchStartX = e.touches[0].clientX;
        touchStartY = e.touches[0].clientY;
        touchScrollX = mapContainer.scrollLeft;
        touchScrollY = mapContainer.scrollTop;
    }
}, { passive: true });

mapContainer.addEventListener('touchmove', function(e) {
    if (e.touches.length === 2 && isTouchZooming) {
        e.preventDefault();
        const dist = getTouchDistance(e.touches);
        const scale = dist / touchStartDist;
        const newZoom = Math.max(ZOOM_MIN, Math.min(ZOOM_MAX, touchStartZoom * scale));
        if (newZoom !== zoomLevel) {
            zoomLevel = newZoom;
            renderMapGrid();
            centerOnPlayer();
        }
    }
    // 单指平移由浏览器原生滚动处理，无需额外代码
}, { passive: false });

mapContainer.addEventListener('touchend', function() {
    isTouchZooming = false;
});

function getTouchDistance(touches) {
    const dx = touches[0].clientX - touches[1].clientX;
    const dy = touches[0].clientY - touches[1].clientY;
    return Math.sqrt(dx * dx + dy * dy);
}
```

### 2.7 双击缩放

```javascript
let lastTapTime = 0;

mapContainer.addEventListener('dblclick', function(e) {
    const cell = e.target.closest('.map-cell');
    if (!cell) return;

    if (zoomLevel < 1.5) {
        zoomLevel = 2.0;  // 双击 → 放大到 2x
    } else {
        zoomLevel = 1.0;  // 再双击 → 回到默认
    }
    renderMapGrid();
    centerOnPlayer();
});
```

### 5.2 改动后

// 基础尺寸（zoomLevel=1 时的尺寸）
const baseSize = Math.max(minSize, Math.min(maxSize, Math.floor(containerWidth / cols)));
const baseHeight = Math.max(isMobile ? 22 : 32, Math.floor(baseSize * 0.6));

## 六、交互流程

### 6.1 首次加载

```
loadMap() → renderMapGrid(zoomLevel=1) → centerOnPlayer()
```

### 6.2 移动后

```
clickMove() → loadMap() → renderMapGrid() → centerOnPlayer()
```

### 6.3 缩放

```
滚轮/双指/+/- → zoomLevel 变更 → renderMapGrid() → centerOnPlayer()
```

### 6.4 拖拽

```
鼠标拖拽/单指滑动 → 容器 scrollTo（浏览器原生）
```

## 七、边界情况

| 场景 | 处理 |
|------|------|
| 缩放到最小，地图完全可见 | 无滚动条，centerOnPlayer 无操作 |
| 缩放到最大，单格占满视口 | 正常滚动，centerOnPlayer 居中 |
| 玩家在地图边缘 | centerOnPlayer 滚动到极限位置，不超出 |
| 移动端单指拖拽 vs 格子点击 | 单指短触 = 点击格子，单指长拖 = 平移（浏览器原生区分） |
| 双指缩放时误触格子 | touchmove 时 e.preventDefault() 阻止后续 click |
| 拖拽 vs 格子点击 | mousedown 在空白处才启动拖拽，mousedown 在格子上不拦截 |
| 窗口 resize | 重新计算 baseSize，保持 zoomLevel，重新居中 |

## 九、不做的

| 功能 | 原因 |
|------|------|
| 小地图（minimap） | 当前地图最大 10x10，缩小时全部可见，不需要 minimap |
| 路径高亮 | 当前 move_range=1，只移动到相邻格，路径就是一条边 |
| 记忆缩放位置 | 每次加载/移动后自动居中，无需记忆 |
