# Vex 前端布局精简 — 设计案

> 目标：精简主视图，只保留地图+日志+动作条，其余收纳到抽屉/按需展示。

---

```

├─────────────────────────────────┬────────────────────────┤
│                                 │ CHRONICLE (flex:4)     │
│         CARTOGRAPHY             │ (日志，带 [TAG] 前缀)  │

│                                 │ │ POI列表 / 脚边道具 │ │
│                                 │ └────────────────────┘ │

浮动组件：
  - 左侧抽屉：玩家属性详情 (SURVIVOR)
```

## 三、各区域详细设计

### 3.1 顶部状态栏

替代原 Header + Footer，仅一行，高度约 24px。

```
┌──────────────────────────────────────────────────────────┐
│ 垃圾平原 · 废墟入口              HP 85/100  SP 12  [背包][属性]│
└──────────────────────────────────────────────────────────┘
```

- **左侧**：`{区域名} · {格名}` — 玩家看地图时视线自然上移看到位置
- **右侧**：`HP {cur}/{max}` `SP {cur}` — 玩家看日志时视线自然上移看到状态
- **按钮**：`[背包]` 打开右侧抽屉，`[属性]` 打开左侧抽屉
- **样式**：`text-[10px]`，`border-b border-fg-dim/50`，与当前 footer 风格一致
- **HP/SP 数值**：HP 低于 30% 时文字变为 `#ccc` 加粗提示危险

### 3.2 主内容区

左右分栏，比例 `65% : 35%`（地图需要更多空间展示网格，右侧面板内容精简后不需要 45%）。

#### 左侧：地图

与现有一致，无结构变化。移除 Header 后地图获得更多纵向空间。

#### 右侧：日志 + 动作条

上下分栏，比例 `flex:4 : flex:6`（动作区占 60%，日志占 40%）。

**日志区 (CHRONICLE)**：
- 保留现有 ASCII 标题栏
- 保留滚动、灰阶高亮、标签前缀
- 无其他变化

**动作区 (ACTIONS)**：
- 保留 ASCII 标题栏
- 内部分为两部分：

```
┌─ ACTIONS ────────────────────────────┐
│                                      │
│  [ 探  索 ]    [区域切换→] (条件显示) │  ← 常驻按钮区
│                                      │
│  ── POI ──────────────────────────   │
│  [搜] 补给储藏箱          可搜索     │  ← POI 列表
│  [搜] 废弃工坊            可搜索     │
│                                      │
│  ── 脚边 ────────────────────────    │
│  [取] 废铁片              ×1         │  ← 脚边道具列表
│  [取] 补给包（？）        ×1         │
│                                      │
│  (空状态: "脚下空无一物")             │
└──────────────────────────────────────┘
```

**常驻按钮区**：
- **探索按钮**：满宽，最醒目（`term-btn block`，加粗+稍大字号）
- **区域切换按钮**：仅当玩家站在出入口格时显示，否则隐藏
- 两个按钮水平排列，探索占 60% 宽度，区域切换占 40%

**POI 列表**：
- 有 POI 时显示，标题行 `── POI ──`
- 每行：`[搜]` 按钮 + POI名 + 状态标签（可搜索/已搜索/冷却中）
- 复用现有 `.tile-row` 样式

**脚边道具列表**：
- 有道具时显示，标题行 `── 脚边 ──`
- 每行：`[取]` 按钮 + 道具名 + 数量
- 近视道具显示 `道具名（？）`
- 复用现有 `.tile-row` 样式

**空状态**：
- 无 POI 且无道具时，显示一行 `脚下空无一物`（`.tile-empty` 样式）
- 有 POI 无道具或反之，只显示有内容的部分

### 3.3 右侧抽屉（道具/装备）

从右侧滑入，宽度 300px，覆盖在地图上方，不挤压布局。

```
┌──────────────────────────────┐
│ ┌─ INVENTORY | ARMAMENT ──┐  │
│ └─────────────────────────┘  │
│                              │
│  (根据选中标签显示内容)       │
│                              │
│  INVENTORY 标签:             │
│  ┌──┐ ┌──┐ ┌──┐            │
│  │1 │ │2 │ │3 │            │
│  └──┘ └──┘ └──┘            │
│  ┌──┐ ┌──┐ ┌──┐            │
│  │4 │ │5 │ │6 │            │
│  └──┘ └──┘ └──┘            │
│                              │
│  ARMAMENT 标签:              │
│  武器  ─ 废铁片              │
│  防具  ─ (空)                │
│  饰品  ─ (空)                │
│                              │
└──────────────────────────────┘
```

- **标签切换**：顶部两个标签 `INVENTORY` / `ARMAMENT`，点击切换，当前标签高亮
- **INVENTORY 标签**：复用现有 `.inv-grid` 3列网格 + `.slot-card` 卡片
- **ARMAMENT 标签**：复用现有 `.eq-slot` 列表
- **打开方式**：点击状态栏 `[背包]` 按钮
- **关闭方式**：点击遮罩 / 点击 `[X]` 按钮 / 按 ESC
- **遮罩**：`bg-black/70`，与左侧抽屉一致
- **动画**：`transform: translateX(100%)` → `translateX(0)`，300ms cubic-bezier

### 3.4 左侧抽屉（玩家属性）

保留现有设计，仅调整入口：
- 移除左侧边缘的 `STATS` 竖排按钮
- 改为状态栏 `[属性]` 按钮触发
- 其余不变

## 七、交互细节

### 7.1 抽屉层级

| 层级 | 组件 | z-index |
|------|------|---------|
| 底层 | 页面内容 | 1 |
| 左侧抽屉遮罩 | drawer-overlay | 250 |
| 左侧抽屉 | player-drawer | 300 |
| 右侧抽屉遮罩 | inv-drawer-overlay | 350 |
| 右侧抽屉 | inv-drawer | 400 |
| Toast | toast-container | 500 |

左右抽屉不会同时打开（打开一个自动关闭另一个）。

### 7.2 键盘快捷键

| 按键 | 行为 |
|------|------|
| ESC | 关闭当前打开的抽屉 / Bottom Sheet |
| `i` | 打开/关闭右侧道具抽屉 |
| `p` | 打开/关闭左侧属性抽屉 |

### 7.3 动作区交互状态

| 条目 | 可交互条件 | 不可交互表现 |
|------|-----------|-------------|
| 探索按钮 | 始终可用（体力不足时后端拒绝） | 体力不足时 disabled + 灰色 |
| 区域切换按钮 | 站在出入口格 | 不显示 |
| 脚边道具 | `ground_items` 非空 | 不显示该条目 |
| POI（可搜索） | 未搜索 / 可重复且冷却结束 | 显示"已搜索"或"冷却中"标签 |
| POI（机制型） | 视具体机制 | — |

所有容器型条目点击后统一打开 Bottom Sheet，内含逐个拾取/搜索操作。
