## 四、关键技术决策

1. **状态机保持两态**：原前端实际只有 normal/battle 两态（pre-battle 是 initPreloadArea 的参数），Vue 版保持一致，避免过度设计
2. **BattleModal 用 Teleport to body**：避免 position: fixed 与父级 transform 冲突（迁移计划风险点 7.3）
3. **打字机 setTimeout 链**：用 onUnmounted 清理 + ref 跟踪 currentTimer / currentSleepResolve（迁移计划风险点 7.3）
4. **碰撞动画**：通过 ref 获取 DOM 元素，操作 class（与 Vue 虚拟 DOM 兼容，只添加/移除临时 class）
5. **伤害数字**：position: fixed + body appendChild（与原前端一致，避免依赖容器定位上下文）
6. **AimMode SVG**：响应式 pathData computed 驱动 SVG path 的 d 属性（替代原前端的 innerHTML）
7. **事件转发**：保持 dataManager.broadcast/listen 模式（battle:started/ended/aim-mode/aim-exit/preload:executed）
8. **markBattleLogPlayed**：直接复用 `vex-vue/src/api/client.ts` 已有函数（任务 12 已完成）
9. **NPC 自动刷新**：store 内部管理定时器，回调调用 store action（自调用 refreshBattle）
10. **播放上下文**：battleStore.playContext ref 供 BattleModal 响应式读取（替代原前端的全局 ctx 变量）
