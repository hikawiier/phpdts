# 地图交互体验深化设计案

## 一、移动路径预览

### 交互
- 鼠标悬停在**可达格**上时，高亮显示从当前格到目标格的移动路径
- 路径用 BFS 最短路径算法计算（基于 neighbors 连通关系）
- 路径上的格子添加 `.cell-path` 高亮样式（区别于 `.reachable` 的悬停高亮）
- 鼠标移出可达格时清除路径高亮
- 迷雾格、不可达格不触发路径预览

### 视觉
- `.cell-path`：极淡的白色背景 `rgba(255,255,255,0.08)` + 虚线边框
- 路径终点（目标格）保持原有 `.reachable:hover` 高亮
- 路径方向指示：路径格子上叠加方向箭头字符（↑↓←→↗↘↙↖），表示行进方向

### 实现
- `map.js`：新增 `findPath(fromPls, toPls)` BFS 函数，返回 pls 数组
- `map.js`：`renderMapGrid()` 中为每个 `.reachable` 格子绑定 mouseenter/mouseleave
- mouseenter：计算路径 → 给路径格子加 `.cell-path` class + 方向箭头
- mouseleave：清除所有 `.cell-path` class 和箭头
- `terminal.css`：新增 `.cell-path` 样式

## 二、键盘方向键移动

### 交互
- 支持 WASD 和方向键（↑↓←→）
- 按键时根据当前格的坐标，计算目标格坐标（当前格 ±1 行/列）
- 查找该坐标对应的 pls，若该 pls 在当前格的 neighbors 中且非迷雾 → 移动
- 若目标格不可达（不在 neighbors / 迷雾 / 不存在）→ 短暂抖动当前格提示无效
- 输入框聚焦时忽略按键（已有逻辑）

### 边界处理
- 目标坐标超出网格范围 → 无效，抖动提示
- 目标坐标无格子 → 无效，抖动提示
- 目标格在 neighbors 但迷雾未点亮 → 无效，抖动提示
- 区域切换格（出口/入口）不通过方向键触发，仍需点击按钮（避免误操作）

### 视觉
- 无效移动时当前格添加 `.cell-shake` class，300ms 后移除
- `terminal.css`：新增 `@keyframes shake` 抖动动画

### 实现
- `map.js`：新增 `handleKeyMove(dx, dy)` 函数
- `map.js`：`initMapInteraction()` 中绑定 keydown 事件
- `map.js`：新增 `shakeCurrentCell()` 视觉反馈
- `terminal.css`：新增 `.cell-shake` 动画
