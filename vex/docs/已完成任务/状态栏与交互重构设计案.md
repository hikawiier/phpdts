# Vex 前端状态栏与交互重构 — 设计案

> 目标：重做状态栏（加入头像+血条+体力条），调整按钮位置使空间映射一致，Bottom Sheet 统一改为居中模态框。

---

## 一、变更总览

| 变更项 | 现状 | 目标 |
|--------|------|------|
| 状态栏 | 单行文字条，text-[10px]，py-1，约24px高 | 带头像+血条的视觉面板，约80px高 |
| 按钮位置 | [背包]左侧开右抽屉，[属性]右侧开左抽屉 | [属性]左侧开左抽屉，[背包]右侧开右抽屉 |
| POI/拾取交互 | Bottom Sheet（底部滑出） | 居中模态框 |
| 状态栏渲染 | map.js 更新位置+HP/SP | player.js 统一渲染整个状态栏 |

---

## 二、状态栏设计

### 2.1 布局

```
┌──────────────────────────────────────────────────────────┐
│ ┌──────────┐  垃圾平原 · 废墟入口     ████████░░ HP 85/100│
│ │  头像     │  [属性]                  ██████░░░░ SP 12   │
│ │  140x80   │                          [背包]            │
│ └──────────┘                                            │
└──────────────────────────────────────────────────────────┘
```

### 2.2 各元素规格

| 元素 | 位置 | 规格 | 数据源 |
|------|------|------|--------|
| 头像框 | 最左侧 | 140×80px，`img/{gd}_{icon}.png` | player_info: gd, icon |
| 位置信息 | 头像右侧上方 | `text-xs`，`text-fg-dim` | mapData: curRegion + curLoc |
| [属性] 按钮 | 头像右侧下方 | `text-xs`，点击开左侧抽屉 | — |
| HP 条 | 右侧上方 | 固定宽120px，高6px，CSS窄条 | player_info: hp, mhp |
| HP 文字 | HP 条右侧 | `HP {cur}/{max}`，右对齐 | player_info: hp, mhp |
| SP 条 | 右侧中部 | 固定宽120px，高6px，CSS窄条 | player_info: sp, msp |
| SP 文字 | SP 条右侧 | `SP {cur}/{max}`，右对齐 | player_info: sp, msp |
| [背包] 按钮 | 右侧下方 | `text-xs`，点击开右侧抽屉 | — |

### 2.3 血条/体力条样式

- **正常状态**：HP 条 `bg-fg-mid`(#888)，SP 条 `bg-fg-dim`(#555)
- **HP < 30%**：HP 条变为 `bg-hi`(#fff) + CSS blink 动画，文字加粗
- **条容器**：`bg-fg-dim/20`，圆角 2px
- **条宽度**：`width: {(cur/max)*100}%`

### 2.4 头像

- 路径：`img/{gd}_{icon}.png`（gd: m/f，icon: 图像编号）
- 容器：`border border-fg-dim/30`，`overflow-hidden`
- 图片加载失败时显示 ASCII 占位符（如 `???`）

## 三、按钮位置调整

### 3.1 变更

| 按钮 | 现位置 | 新位置 | 目标抽屉 |
|------|--------|--------|----------|
| [属性] | 状态栏右侧 | 头像右下方（左侧区域） | 左侧抽屉 |

## 四、Bottom Sheet → 居中模态框

### 4.1 变更

所有 Bottom Sheet 场景统一改为居中模态框：

| 场景 | 现交互 | 新交互 |
|------|--------|--------|
| POI 搜索 | Bottom Sheet 展示 POI 详情 + 搜索按钮 | 模态框展示 POI 详情 + 搜索按钮 |
| 道具拾取 | Bottom Sheet 展示道具列表 + 拾取按钮 | 模态框展示道具列表 + 拾取按钮 |

### 4.2 模态框设计

```
┌─────────────────────────────────┐
│ ── 补给储藏箱 ──────────── [X] │
│                                 │
│  补给包          [取]           │
│  废铁片（？）    [取]           │
│                                 │
└─────────────────────────────────┘
```

- **宽度**：360px，最大 `90vw`
- **遮罩**：`bg-black/60`，点击遮罩关闭
- **位置**：垂直+水平居中
- **关闭方式**：点击 [X] / 点击遮罩 / 按 ESC
- **动画**：`opacity 0→1` + `scale(0.95)→1`，200ms ease-out
- **样式**：`border border-fg-dim/50`，`bg-bg`，与终端风格一致

### 4.3 DOM 结构

```html
<!-- 模态框遮罩 -->
<div class="modal-overlay" id="modalOverlay">
    <!-- 模态框主体 -->
    <div class="modal" id="modal">
        <div class="modal-header">
            <span id="modalTitle" class="text-fg-bright text-xs tracking-widest"></span>
            <button id="modalCloseBtn" class="text-fg-dim hover:text-hi cursor-pointer">[X]</button>
        </div>
        <div id="modalBody" class="modal-body"></div>
    </div>
</div>
```

### 4.4 删除的 DOM

| 元素 | 处理 |
|------|------|
| `#bottomSheetOverlay` | 删除 |
| `#bottomSheet` | 删除 |
| `#sheetHeader` / `#sheetSub` / `#sheetBody` | 删除 |
| `#sheetCloseBtn` | 删除 |

## 五、JS 模块变更

### 5.1 `player.js`（主要变更）

- **接管状态栏渲染**：新增 `renderStatusBar()` 函数，统一渲染头像、位置、HP/SP 条、按钮
- **数据来源**：
  - 位置信息：从 `mapData`（data.js 导出）读取 `curRegion` / `curLoc`
  - HP/SP/头像：从 `player_info` API 数据读取
- **订阅事件**：
  - `map:loaded` → 更新位置信息
  - `game:action-completed` → 重新拉取 player_info 并刷新状态栏
- **[属性] 按钮**：绑定点击事件，打开左侧抽屉（原 `#drawerToggle` 功能）
- **移除**：原 `#drawerToggle` 事件绑定

### 5.2 `map.js`

- **移除**：`updateStatusBar()` / `updateHeaderStatus()` 函数
- **移除**：对 `#statusBar` / `#headerStatus` / `#locationInfo` / `#hpInfo` / `#spInfo` 的 DOM 操作
- **保留**：`mapData` 导出不变（player.js 从中读取位置）

### 5.3 `tile-action.js`

- **Bottom Sheet → 模态框**：所有 `bottomSheet` 相关 DOM 操作改为 `modal` 操作
- **渲染逻辑不变**：POI 列表 + 脚边道具列表 + 常驻按钮区
- **点击 POI/道具**：打开模态框而非 Bottom Sheet

### 5.4 `inventory.js`

- 无变更（已移入右侧抽屉，不受本次影响）

### 5.5 `app.js`

- **模态框初始化**：`#modalOverlay` 点击关闭、`#modalCloseBtn` 点击关闭、ESC 关闭
- **移除**：Bottom Sheet 相关初始化
- **ESC 键**：关闭优先级 — 模态框 > 抽屉

### 5.6 `data.js` / `command-queue.js` / `data-manager.js` / `log.js` / `utils.js` / `debug.js`

- 无变更

| 按键 | 行为 |
|------|------|
